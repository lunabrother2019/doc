记忆系统

2025 顶会新增

4 篇
S1
Memory in the Age of AI Agents: A Survey ↗
2025.12 · arXiv · Yuyang Hu, Shichun Liu et al.
Factual / Experiential / Working Memory Memory Taxonomy Benchmark Compilation RL Integration Multi-agent Memory Trustworthiness
推荐

目前最全面的 Agent 记忆综述。明确区分了 Agent Memory 与 LLM Memory、RAG、Context Engineering 的边界。从功能维度将记忆分为事实记忆（Factual）、经验记忆（Experiential）、工作记忆（Working）；从动态维度分析记忆的形成、演化和检索过程。

额外贡献：编制了记忆基准和开源框架的完整目录，并展望了记忆自动化、RL 集成、多模态记忆、多 Agent 记忆和可信性等前沿方向。配套 GitHub Paper List 持续更新。

S2
MemoryOS: Memory OS of AI Agent ↗
2025 · EMNLP 2025 Oral · Jiazheng Kang, Mingming Ji, Zhe Zhao, Ting Bai
Memory Operating System Three-Level Storage Short/Mid/Long-term Memory FIFO + Segmented Paging F1 +49%
推荐

借鉴操作系统内存管理思想，设计了 Agent 的三级记忆架构：短期记忆、中期记忆、长期个人记忆，配套四个核心模块（存储、更新、检索、生成）。

关键机制：短期→中期更新遵循对话链 FIFO 原则，中期→长期更新采用分段页式组织策略。在 LoCoMo 基准上 F1 提升 49.11%，BLEU-1 提升 46.18%。是将 OS 概念迁移到 Agent 记忆的代表性工作。

S3
In Prospect and Retrospect: Reflective Memory Management for Long-term Personalized Dialogue Agents ↗
2025 · ACL 2025 · Zhen Tan, Jun Yan, I-Hung Hsu, Rujun Han et al.
Prospective Reflection Retrospective Reflection Online RL Retrieval Multi-granularity Summarization LongMemEval +10%
推荐

提出反思式记忆管理（RMM），融合前瞻与回顾两个方向的反思：

  • 前瞻反思（Prospective）：跨粒度（语句/轮次/会话）动态摘要，写入个性化记忆库
  • 回顾反思（Retrospective）：用在线 RL 基于 LLM 引用证据迭代优化检索策略

解决了两个痛点：固定记忆粒度导致语义碎片化，固定检索机制无法适应多样对话场景。LongMemEval 上准确率提升 10%+。

S4
Autonomous Memory Augmentation for LLM Agents ↗
2025 · EMNLP 2025
Autonomous Memory Management Write / Update / Forget Self-Determined Timing

Agent 自主决定何时写入、更新、遗忘记忆，而非依赖预设规则（如 Smallville 的重要性阈值）。将记忆管理从"规则驱动"推向"Agent 自治"，是记忆系统走向自动化的重要一步。

反思机制

正面经验反思

1 篇
S5
Sweet&Sour: Positive Experience Reflection for Agents in Interactive Text Environments ↗
2024 · NeurIPS 2024
Positive Experience Reflection Success + Failure Reflection Managed Memory Small LLM Effectiveness
推荐

Reflexion 的重要补充。Reflexion 只在失败后反思，本文提出 Sweet&Sour：每完成一个子目标也进行反思（正面经验），并立即写入可用记忆。

解决了两个问题：(1) Agent 初始就成功时 Reflexion 无法触发；(2) 小模型上 Reflexion 效果衰减。在 closed 和 open-source LLM 上均有效，特别是在小模型场景下优势明显。

社会仿真与框架

Smallville 思想的直接继承者

5 篇
S6
Concordia: A Library for Generative Social Simulation ↗
2024 · Google DeepMind · NeurIPS 2025 Competition Track
Game Master Architecture Mediated Multi-Agent Games Mixed-Motive Scenarios Generalization Evaluation
推荐

Google DeepMind 开源的生成式社会仿真库。核心设计：引入 Game Master 角色作为环境中介，形式化 LLM 在多 Agent 博弈中的交互。支持合作/竞争/混合动机等多种社交场景。

已有 NeurIPS 2025 论文用 Concordia 评估 LLM Agent 在混合动机场景下的泛化能力。2025 年举办了 NeurIPS Concordia Contest 竞赛。

S7
Sotopia / SOTOPIA-S4: Social Intelligence Evaluation and Simulation ↗
2024-2025 · CMU
Social Intelligence Benchmark 90 Scenarios / 40 Characters Goal Completion Believability Evaluation Secret-keeping
推荐

CMU 出品的 Agent 社交智能评测框架：90 个社交场景 + 40 个带个性/职业/秘密的角色。评测维度包括目标完成度、可信度、知识运用、秘密保守等。

SOTOPIA-S4（2025）升级为用户友好的大规模社会仿真系统，支持灵活定制和扩展。是评估 Agent "像不像人"的标准基准之一。

S8
SocioVerse: A World Model for Social Simulation Powered by LLM Agents and A Pool of 10 Million Real-World Users ↗
2025.04 · arXiv · Fudan University
10 Million User Pool World Model for Social Sim User Engine / Scenario Engine / Behavior Engine Politics / News / Economics Validation

复旦大学提出的社会仿真世界模型，最大亮点：1000 万真实用户池（来自社交媒体数据，相当于匈牙利或希腊的全国人口）。

四大组件：Social Environment（注入实时真实信息）、User Engine（重建用户画像）、Scenario Engine（编排仿真流程）、Behavior Engine（驱动 Agent 复现人类行为）。在政治、新闻、经济三个领域验证了群体动态的多样性、可信度和代表性。

S9
PolicySim: An LLM-Based Agent Social Simulation Sandbox for Proactive Policy Optimization ↗
2026.03 · arXiv
Proactive Policy Evaluation Contextual Bandit + Message Passing SFT + DPO for User Agent Echo Chamber / Polarization Pre-deployment Testing

用 Agent 仿真沙盒在部署前主动评估社交平台干预政策，替代传统的事后 A/B 测试。两大核心组件：

  • 用户 Agent 模块：通过 SFT + DPO 微调实现平台特定的行为真实感
  • 自适应干预模块：用上下文赌博机 + 消息传递捕捉动态网络结构

目标场景：推荐/内容过滤等政策可能无意中放大回音室和极化效应，PolicySim 能在上线前发现风险。

S10
AgentVerse: Multi-LLM-Agent Deployment for Task-Solving and Simulation ↗
2023-2025 · OpenBMB (Tsinghua)
Dual-Mode Framework Task-Solving Mode Simulation Mode Pluggable Agent Design

清华 OpenBMB 开源的多 Agent 部署框架，独特之处：同时支持任务求解和社会仿真两种模式。任务模式下 Agent 协作解决问题（类似 ChatDev），仿真模式下 Agent 在虚拟社会中自主交互（类似 Smallville）。可插拔的 Agent 设计使其易于扩展。

具身/开放世界

与 Smallville 同期的标志性工作

1 篇
S11
Voyager: An Open-Ended Embodied Agent with Large Language Models ↗
2023 · NeurIPS · Wang, Xie, Jiang, Mandlekar, Xiao, Zhu, Fan, Anandkumar
Lifelong Learning Agent Skill Library Automatic Curriculum Iterative Prompting Self-Verification Minecraft
必读

与 Smallville 同期的另一个标志性工作。Voyager 是 Minecraft 中首个 LLM 驱动的终身学习具身 Agent，通过 GPT-4 黑盒调用（无需微调）实现持续探索和技能获取。

三大核心组件：

  • 自动课程（Automatic Curriculum）：最大化探索多样性
  • 技能库（Skill Library）：用可执行代码存储和检索复杂行为，不断增长
  • 迭代 Prompting + 自验证：整合环境反馈、执行错误进行程序改进

效果：获取独特物品 3.3x，移动距离 2.3x，解锁科技树速度 15.3x（vs 前 SOTA）。

与 Smallville 的对比：Smallville 关注社会行为涌现，Voyager 关注技能积累和开放世界探索。两者共同定义了 2023 年 LLM Agent 的两大方向——社会仿真 vs 具身探索。

游戏/生活仿真

Smallville 思想的产品化

1 篇
S12
Unbounded: A Generative Infinite Game of Character Life Simulation ↗
2024.10 · arXiv
Generative Infinite Game Two-Agent Architecture World Simulation Model User Interaction Model IP-Adapter for Visual Consistency Gemma-2B Distillation

将 Smallville 的思想做成可玩的消费级产品。受 James P. Carse "有限与无限游戏"启发，Unbounded 是完全由生成模型驱动的无限生命仿真游戏。

双 Agent 架构：

  • 世界仿真模型：设置环境、生成叙事、追踪角色状态、模拟行为
  • 用户交互模型：管理玩家交互，包括叙事推进、环境变化、角色行动

技术亮点：从 GPT-4o 蒸馏到 Gemma-2B（仅 5000 样本），性能接近 GPT-4o；使用 Dynamic Regional IP-Adapter 保持角色在不同环境下的视觉一致性。
