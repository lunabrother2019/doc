LLM User Simulator：双模型 ensemble（唯一有代码）

CityU Hong Kong + 快手（Zijian Zhang 等）。核心设计：不只靠 LLM prompt，而是用逻辑模型（LLM 提取 item 特征 + 蒸馏用户情绪 + 显式偏好规则）和统计模型（从交互 log 捕捉行为模式）做 ensemble。两个模型各自产出预测，组合后生成高保真用户行为。

关键贡献：可量化仿真保真度——不只是"看起来像"，而是有指标衡量 simulator 和真人的差距。产出的合成数据可直接训练 RL 推荐器（A2C/DQN/PPO/TRPO）。

代码：GitHub（26 stars，last push 2025-01-06）

3

SimUSER：最接近 L3 的工作（无代码）

四模块架构直接继承 Smallville：persona（从历史数据自动推断，含 background+personality）、memory（episodic + knowledge-graph）、perception（处理推荐内容含缩略图/评论）、brain（决策）。

最重要的贡献：已做 offline A/B 验证
验证了 thumbnail 对 CTR 的影响、曝光效应（mere-exposure effect）、评论对 engagement 的影响——这些微观行为现象与真人行为一致。更关键的是：用 offline A/B 结果调参后，真实用户 engagement 提升——罕见的端到端验证。

遗憾：无公开代码（GitHub 404）。但其四模块设计和 A/B 验证方法论可以复现。

4

Lusifer：Profile 动态演化

University of Windsor（Danial Ebrat 等），IEEE ICMI 2025。核心创新：每次交互后 LLM 增量更新 user profile 并生成偏好变化的自然语言解释。只用最近 40 条交互（强调 recency），处理冷启动靠文本元数据推理而非协同过滤。

与 AFL (DD59) 的区别：Lusifer 只做 user side simulator，不做双 Agent 共演化。但其"profile 增量更新+可解释 rationale"机制可以嫁接到任何 Agent 架构上。

5

PUB：心理学人格驱动

RMIT University（Chenglong Ma 等），SIGIR 2025。唯一把Big Five 人格特质（OCEAN）正式嵌入 RecSys simulator 的工作。从行为 log + review 用 psycholinguistic correlates 推断人格（如 category entropy→Openness，review consistency→Conscientiousness），然后生成人格条件化的交互数据。

发现：高 Openness 用户探索范围更广，高 Conscientiousness 用户评分更一致——与心理学文献一致。

PUB 的人格驱动思路和 Agent4Rec 的三维社交特质（activity/conformity/diversity）互补：Agent4Rec 用行为学维度，PUB 用心理学维度。两者结合可能产生更真实的 persona 初始化。

对复现计划的影响

关键判断
  • LLM User Simulator 的"可量化保真度"方法可直接用于我们的 L1 实验
  • SimUSER 的 A/B 验证方法论是我们 L3 路线的最佳参考（虽然无代码需自己实现）
  • Lusifer 的 profile 增量更新可嫁接到 RecAgent 上，观察对闭环稳定性（L2）的影响
  • PUB 的 Big Five 人格可作为更丰富的 persona 初始化方案
