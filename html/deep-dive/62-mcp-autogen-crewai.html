MCP：Agent↔Tool 的 USB-C

Anthropic 2024 年底发布。类比 USB-C 为设备提供统一接口，MCP 为 AI agent 提供统一的 tool/resource/prompt 访问层。

三层架构

  • Host：LLM 应用（Claude Desktop / IDE 等）
  • Client：管理连接生命周期
  • Server：暴露 Tools / Resources / Prompts 三种 primitive

三大 Primitive

  • Tools：可调用函数（如"搜索数据库""发送邮件"）
  • Resources：可读数据源（如"项目文件列表""数据库 schema"）
  • Prompts：预定义提示模板
与 A2A 的互补关系
DD52 Google A2A 管 agent↔agent 横向通信，MCP 管 agent↔tool 纵向调用。两者正交互补。

AutoGen → MAF：对话驱动的 Agent 编排

Microsoft Research 2023.08 推出 AutoGen（57.3k stars），2026 年进入 maintenance，后继者 Microsoft Agent Framework (MAF)（9.7k stars，2025.04 创建）。

核心设计：Conversable Agent

每个 agent 可发送/接收消息并自主决策——通过对话而非固定流水线驱动协作。与 MetaGPT 的 SOP 固定管线不同，AutoGen 强调动态对话驱动。

三层 API

  • Core API：message passing + event-driven runtime，支持分布式
  • AgentChat API：简化的 two-agent / group chat 原型
  • Extensions API：LLM client、code execution 等插件

MAF 继承设计并加入企业特性：稳定 API、A2A + MCP 跨 runtime 互操作、长期支持。

CrewAI：角色声明式 Crew 组建

João Moura 2023.10 创建（49.4k stars），从零构建（不依赖 LangChain）。

核心概念：Role-Playing 三元组

每个 Agent 有 role（角色）+ goal（目标）+ backstory（背景故事），YAML 声明式配置。

双模式设计

  • Crews：自主协作 agent 团队，sequential / hierarchical process，agent 可自主 delegate
  • Flows：event-driven 精确控制流，面向生产环境

Memory 系统

内置三层 memory：short-term / long-term / entity memory——直接呼应小镇的 memory stream 分层设计。
