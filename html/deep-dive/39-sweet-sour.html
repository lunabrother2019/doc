Sweet&Sour — 成功经验也值得反思（不只从失败学习）后加

一句话定位

Sweet&Sour 是对 Reflexion 反思范式的一次"对称补全"：Reflexion 只在失败（sour）后反思，Sweet&Sour 增加了成功（sweet）后的反思，并引入短期/长期双缓冲的管理记忆机制，让成功经验可以在同一轮尝试内立即复用，而不必等到下一轮重开。

一句话摘要
"别只从失败里学习——人类从成功里学到的更多。"Sweet&Sour 让 LLM Agent 在达成每个 subgoal 后追加一段"为什么成功"的反思，并用 short-term buffer 在当前 episode 内立即注入 prompt；episode 结束再将其归并到 long-term 记忆，从而打破 Reflexion "只有重开一轮才获益"的闭环。
2

动机：Reflexion 的三个盲区

作者首先把 Reflexion 范式放到显微镜下，梳理出三个在实际部署中被反复观察到的失效模式：

① 一上来就顺 → 反思失效
如果 agent 在第一次尝试中就部分成功（拿到部分 reward 但没完成全部 subgoal），Reflexion 没有"失败信号"去触发反思。它只会把 trajectory 原样塞回去，丧失了进一步加深正确策略的机会。
② 小模型不会反思
Reflexion 假设 LLM 有稳健的自我诊断能力。但在 Llama 8B 这类小模型上，Reflexion 的诊断经常"幻觉式归因"——写出一段看似合理、实则错误的反思，反而把下一轮带偏。
③ 依赖外部反馈
必须等 Evaluator 明确判"失败"才能触发反思。对于部分奖励、稀疏奖励、或没有明确结束信号的任务，Reflexion 不知道何时反思。
核心洞察：反思是对称的
现有方法（Reflexion、Self-Refine、Retroformer 等）的反思对象都是"出错了什么"。但人类学习是对称的——遇到一个有效的策略时，我们会在内心默念"原来这样做是对的，下次类似情况继续这样"。Sweet&Sour 把这种"success rehearsal"的认知操作显式化：每次 reward 增加时，query LLM 去"verbalize what made the current policy successful"。

为什么"同一 episode 内立即可用"很重要？

Reflexion 的记忆粒度是跨 attempt 的——反思只有在下一轮重开时才会被注入 prompt。这意味着：即使 agent 在 step 30 想明白了某个道理，这个道理也要等到下一次 attempt 的 step 1 才能生效，中间 step 30→step 150 的所有决策都还在"老脑子"上。Sweet&Sour 的 short-term buffer 让反思在同一 trajectory 内就能影响后续 step，解决了反思延迟问题。<待实证>（论文未正面量化此"延迟"收益，但图 1 的对比图示清晰展示了"Next timestep"与"Next attempt"的差异）

3

双流反思 + 管理记忆

Sweet&Sour 的技术方案由两个正交组件构成：（A）双流反思——在成功与失败两端都生成反思；（B）双缓冲记忆——区分短期与长期存储。

A. 双流反思（Sweet / Sour）

🍬 Sweet：成功经验反思

  • 触发：subgoal 达成（reward 增量 > 0）
  • Prompt 要点：让 LLM "extrapolate from"当前策略，口头化"what made the current policy successful"以及"what can be generalized"
  • 产物：一段自然语言的成功策略抽象（可迁移的启发式）
  • 去向：先进 short-term buffer，与 (obs, action, reward) 一同打包为 tuple (reflectiont, ot, at, rt)

🍋 Sour：失败经验反思

  • 触发：一次 attempt 失败（达到 step 上限或明确报错）
  • Prompt 要点：沿用 Reflexion 的诊断型 prompt——"devise a concise, new plan of action that accounts for your mistake with references to specific actions that you should have taken"
  • 产物：对错因的诊断 + 下轮改进建议
  • 去向：直接进 long-term memory，供下一次 attempt 开始时注入 prompt
为什么 sweet 反思比 sour 反思更便宜
sour 反思需要 agent 具备"自我诊断能力"——找出做错的原因，这在小模型上极其困难。但 sweet 反思只需要 agent "复述已经有效的做法"——这是一个描述性任务而非归因性任务，对 LLM 的认知负担小得多。这解释了为什么 Sweet&Sour 在 Llama 8B 上的提升幅度（+10.8）仍然显著，而纯 Reflexion 在小模型上几乎毫无起色（21.7 vs ReAct 20.5）。

B. 管理记忆（Managed Memory）

为了让 sweet 反思能够"当下即用"，作者引入了一个 dual-buffer 的记忆结构：

Short-term Buffer（短期缓冲）
存放当前 episode 内产生的 sweet 反思。在每次 LLM 调用时，当前短期缓冲中的所有反思都会被注入 prompt，使得"在 step t 产生的成功启发可以立即影响 step t+1 的决策"。
Long-term Memory（长期记忆）
跨 episode 持续累积。sweet 反思会在 episode 结束（无论成功或失败）后被"固化"迁移过来；sour 反思则绕过 short-term，失败即刻进入 long-term，供下一次 attempt 使用。

记忆迁移规则

  1. subgoal 达成 → 生成 sweet 反思 → 进 short-term
  2. episode 完成（达成最终目标） → 整个 short-term 归并进 long-term
  3. episode 失败（达到 150 step 上限或出错） → 生成 sour 反思 → 直接进 long-term，同时终止 short-term 收集
  4. 下一次 attempt → 重置 short-term，从 long-term 检索相关反思作为 demo 注入
决策时刻 prompt 构造promptt = Demo + SubGoals + LongTermMem + ShortTermMem<t + Trajectory<t
设计精髓
Reflexion 的反思粒度是 episode（跨尝试）；Sweet&Sour 的 sweet 反思粒度是 subgoal（段内即时）。这是一个看似微小但影响深远的改动——它把"反思"从 outer-loop 的策略更新下沉到 inner-loop 的决策链路里，既避免了等下一轮才能生效的滞后，又把成功经验及时固化下来防止遗忘。
4

实验：ScienceWorld 基准

4.1 为什么选 ScienceWorld 而非 ALFWorld

作者明确说明：放弃了 ALFWorld 和 TWC，原因是对当前 LLM-based agent 而言这些基准过于简单，容易在任何反思方法下都撞到上限。ScienceWorld 则提供了：

  • 10 个互联场景（温室、工作坊等）
  • 200+ 可交互物体 与 25 个 action template
  • 30 个不同任务，每个最多 10 变体（如"煮沸"、"测量电阻"、"生长植物"）
  • 平均最优决策深度 50 步，step 上限 150
  • 稀疏 subgoal reward（0-100 分）

4.2 对比方法

  • CALM：基于 DRRN + fine-tuned 因果语言模型的 rerank 方法（非 LLM agent 基线）
  • ReAct：无反思，纯 THINK+ACT 的 few-shot 基线
  • Reflexion：最多 4 轮尝试，失败时反思并注入下一轮
  • Sweet&Sour (ours)：同上 4 轮 + sweet 反思 + 管理记忆

4.3 测试模型（参数量递减）

  • GPT-4o（gpt-4o-2024-08-06）— 闭源大模型代表
  • Mistral Large 2（mistral-large-2407）— 开源中大模型
  • Llama 3.1 8B Instruct — 小模型代表

4.4 主结果（平均 score，越高越好）

消融结论
把 sweet 反思关掉（只保留 sour 反思），性能立刻回落到接近 Reflexion 的水平（Llama 24.6 ≈ 21.7、Mistral 31.1 ≈ 27.6、GPT-4o 44.9 ≈ 45.3）。这证明提升的核心来源正是"成功反思"本身，而不是管理记忆结构带来的副作用。

4.5 "Anti-Tilt"现象：中等难度任务的关键差距

作者通过任务难度分层观察到一个有趣现象——称之为 Anti-Tilt（防滑坡）：

任务难度典型任务表现模式
极难 1-1 Boil, 8-2 Identify life 2 所有方法都接近 0，反思机制共同失效
简单 4-2 Find2, 7-1 Lifespan 1 LLM 原生能力就能完成，各方法差距小
中等 3-2 Power2, 3-3 Conductivity1 出现关键分化：S&S 远超 Reflexion

最鲜明的例子是任务 3-2 (Power2)：GPT-4o 上 ReAct 55.6，Reflexion 反而跌到 24.7，Sweet&Sour 达到 58.0。作者的解释：Reflexion 因为初始已经部分成功，没有明确"失败"去触发反思，结果反而被自己无意义的重启拖累（"got stuck despite its self-reflection"）；而 Sweet&Sour 在每个 subgoal 处都反思，把初始的成功动能固化为可复用的策略，实现"乘胜追击"。

反直觉发现
在任务 3-2 上 Reflexion 比 ReAct 还差（24.7 vs 55.6）——这是 Reflexion 的一个重要负面案例：当 agent 已经走在对的路上时，强行反思反而会破坏已有的好策略。这也佐证了 Sweet&Sour 论文所说的"反思限制 ①：一上来就顺时失效"。<待实证>（解释是作者推测，可能还有 prompt 长度、attempt 预算分配等混淆因素）

4.6 小模型收益最大

观察绝对分数的变化比例：

  • GPT-4o：45.3 → 54.6，相对提升 +20.5%
  • Mistral Large 2：27.6 → 44.6，相对提升 +61.6%
  • Llama 3.1 8B：21.7 → 32.5，相对提升 +49.8%

这支持了论文核心论点：Sweet&Sour 特别适合计算资源受限的场景——小模型本来写不出高质量 sour 反思，但可以写出"复述成功做法"的 sweet 反思。

三者共享的核心信念

Reflexion、ExpeL、Sweet&Sour 其实构成一条演化链——不断扩大"反思"所覆盖的经验范围：

  • Reflexion（2023）：只反思失败、单一 buffer
  • ExpeL（2024）：引入轨迹对比（trajectory comparison），从成功-失败轨迹对里蒸馏 insight
  • Sweet&Sour（2024）：显式把成功也作为独立反思源，并把反思粒度细化到 subgoal、记忆粒度细化到 short/long-term
ExpeL 已覆盖 trajectory comparison，Sweet&Sour 的增量在哪？
ExpeL 是"事后诸葛亮式"对比——任务全部结束后再去挑两条轨迹对比出 insight，这需要一批成功+失败样本才能启动。Sweet&Sour 则是"即时确认式"——每个 subgoal 成功的瞬间就 verbalize 一次，不需要拿另一条失败轨迹做对照。两者在"从成功中学习"这个大方向上一致，但 Sweet&Sour 更轻量、更在线（online），且不依赖大批量轨迹积累。
如果把 Sweet&Sour 投射回 Smallville 的 Reflection 机制：斯坦福小镇的 Reflection 在 importance 累积到阈值时无差别地对最近记忆做总结，并不区分"这段记忆是好经历还是坏经历"。Sweet&Sour 的启示是——将来可以在 Memory Stream 上分别维护"成功反思池"和"挫折反思池"，让角色在不同情绪/场景下检索不同侧的经验（开心时强化"我成功的原因"、失落时对照"我失败的教训"），这是 Smallville 社会模拟的一个很自然的扩展方向。<待实证>

FAQ

Q1：Sweet&Sour 只是多加了一个 prompt——这真的有那么大影响吗？小模型+17 分的提升是不是过拟合 ScienceWorld？
这是一个合理质疑。几点观察：
（1）消融实验清楚表明——拿掉 sweet 反思后，Mistral 从 44.6 跌到 31.1，几乎丢光全部增益，证明提升来自 sweet 反思本身而非 prompt 工程或 buffer 结构；
（2）论文确实只在 ScienceWorld 单一基准上验证（作者在 Limitations 里也坦承"single environment"），所以是否能迁移到 WebArena、AlfWorld Hard、真实软件工程任务仍需验证<待实证>；
（3）"verbalize 成功原因"这个操作的泛用性在认知科学上有长期支持（self-explanation effect），因此我倾向于认为效应真实存在，但具体数值可能随任务而浮动；
（4)一个潜在混淆：sweet 反思必然让 prompt 变长，是否仅仅因为 context 更丰富而不是"反思内容正确"？论文未做 prompt-length 对照实验。
Q2：如果 agent 在 step 5 因为运气或幻觉"误判"自己成功了，生成一段错误的 sweet 反思并注入 short-term buffer，会不会导致后续决策雪崩？这是不是比 Reflexion 更脆弱？
非常尖锐的问题。论文的隐含假设是：subgoal 的达成由环境 reward 判定，而非 LLM 自评——因此"误判成功"要求环境误报 reward，这在 ScienceWorld 这类 well-defined 仿真中概率极低。但这个架构确实有两个脆弱点：
（a）虚假归因：subgoal 真的成功了，但 agent 把成功归因到错误的因素上（"我赢是因为我先拿了锤子"，实际上与锤子无关）。这会被 verbalize 进 short-term buffer，并被后续 step 作为行动依据。小模型尤其容易陷入此陷阱，但目前结果显示小模型反而提升最大——猜测是复述策略本身（描述性）比归因（解释性）容易得多，虚假归因的概率被天然压低；<待实证>
（b）过拟合局部启发：sweet 反思在 step 10 得出"先开灯再找物体"的启发，但这只对当前房间成立，后续房间里变成误导。论文没有讨论过期反思的 invalidation 机制。
实践中建议：限制 short-term buffer 大小、定期让 LLM 自检 buffer 中的反思是否仍然有效，以及在环境奖励可靠性存疑时降级为 Reflexion-only 模式。
