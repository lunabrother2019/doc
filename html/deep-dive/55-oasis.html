三层架构

1
Environment Layer — 动态社交网络图 + 帖子信息流，实时更新关注关系与内容状态。支持 Twitter（关注制）和 Reddit（板块制）两种拓扑。
2
Action Layer — 23 种离散动作：follow / unfollow / mute / comment / repost / like / dislike / create_post / search / report / block 等。Agent 每轮从 action space 中选择执行。
3
Recommendation Layer — 内置两套推荐算法：interest-based（向量相似度）和 hot-score-based（热度衰减排序）。模拟真实平台的内容分发机制。

关键设计选择

  • 无 memory stream — Agent 靠 profile + prompt + 当前 feed 驱动，没有跨轮记忆
  • 无 reflection — 不做自我反思或高层合成
  • Activation probability — 每轮只有一定比例的 Agent 活跃，控制 LLM 调用成本
  • Async event-driven — asyncio + SQLite 持久化，支撑百万级并发
成本参考
100 Agent × 1 step ≈ 33.5 万 input tokens（GPT-4o-mini）。百万 Agent 一轮的成本是天文数字——所以 activation probability 是必需的工程手段。

规模实验：从 100 到 1,000,000

OASIS 的核心贡献是证明群体现象随规模变化——这是此前小规模仿真器（小镇 25 人 / AgentSociety 10K）无法观察的：

规模观察
100基础社交行为可复现；群体现象不明显
1,000信息级联开始出现
10,000群体极化显著加剧
100,000从众行为比例上升；观点多样性开始丰富
1,000,000所有群体现象amplified；规模本身成为涌现的驱动力
关键发现
Larger scale amplifies group dynamics 且 produces more diverse viewpoints。这暗示小镇式 25 人仿真在原理上就无法观测到某些社会现象——有些涌现只在大规模时才存在。
4

三大涌现群体现象

① Information Cascade（信息级联）

传播速度随规模呈超线性增长——100 人时一条帖子平均传播 3 跳，10 万人时可达 12+ 跳。推荐算法放大了 viral 效应。

② Group Polarization（群体极化）

在 10K+ 规模时，持有相似观点的 Agent 越来越聚集在一起（echo chamber），极端观点被放大。推荐系统的 interest-based 算法加剧了这一效应。

③ Herd Effect（从众效应）

从众行为比例随群体增大而上升——当一个帖子获得大量 likes 后，后续 Agent 给 like 的概率显著提升，与社会心理学中的 conformity 文献一致。

对照小镇：两条完全相反的路

维度Smallville (2023)OASIS (2024)
规模25 人1,000,000 人
个体认知深度memory stream + reflection + planning无记忆 / 无反思 / 无规划
行为驱动记忆检索 + 反思合成profile + prompt + 当前 feed
环境物理小镇 (2D 地图)社交平台 (Twitter/Reddit)
涌现类型叙事性（派对、选举、浪漫）统计性（极化、级联、从众）
验证方式定性 + credibility与社会学文献定性趋势对比
推荐系统无内置两套算法，是关键变量
OASIS 和小镇代表了 Agent 仿真的两个极端：小镇追求"少而深"——用 25 个高认知 Agent 涌现叙事；OASIS 追求"多而浅"——用百万个低认知 Agent 涌现统计。两者互补：小镇回答"Agent 能不能像人"，OASIS 回答"百万 Agent 能不能像社会"。未来的融合方向可能是：在 OASIS 的百万规模上给关键 Agent 加上小镇的 memory + reflection——形成分层认知架构。
