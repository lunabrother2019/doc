论文概述：从 25 到 10,000+

斯坦福小镇（Generative Agents, 2023）以 25 个 Agent 在沙盒环境中展现了令人惊叹的社会行为涌现。但一个根本性问题始终悬而未决：这种架构能否扩展到真实的社会规模？ AgentSociety 由清华大学团队提出，直接回答了这个问题 —— 将仿真规模提升到 10,000+ 个 Agent，产生超过 500 万次交互，研究大规模社会动态。

核心贡献
AgentSociety 不仅是一个规模扩展实验，更是一个系统性的架构研究。它证明了 Generative Agents 架构的可扩展性，同时识别了扩展过程中的关键瓶颈，并提出了分层记忆、异步调度、轻量推理等技术方案。

扩展挑战：三座大山

将 Generative Agents 从 25 扩展到 10,000+ 面临三个根本性挑战，每一个都需要架构级别的解决方案。

挑战一：计算成本爆炸

LLM 调用量的超线性增长

25 个 Agent 扩展到 10,000 意味着 400 倍的基础 LLM 调用量。但实际情况更糟 —— 交互对数呈 O(N²) 增长：

交互复杂度 潜在交互对 = N × (N-1) / 2 ≈ 5000万 （N = 10,000）

即使只有一小部分潜在交互实际发生，LLM 调用量仍然是天文数字。按斯坦福小镇的架构设计，每个 Agent 的每次行动都需要 LLM 调用（规划、行动选择、对话生成、反思），这在万人规模下完全不可行。

挑战二：行为一致性

大规模下的人格与行为连贯

  • 人格漂移：经过数千轮交互后，Agent 的行为可能偏离初始人格设定
  • 记忆过载：大量交互产生的记忆远超 Agent 的处理能力，导致检索质量下降
  • 上下文窗口限制：即使是百万 token 的上下文窗口，也无法容纳万次交互的完整历史

挑战三：涌现复杂度

不可预测的宏观动态
25 个 Agent 的涌现行为已经令人惊讶（如自发组织情人节派对）。10,000 个 Agent 的交互将产生更高阶的涌现现象：社区自组织、信息瀑布、集体决策、舆论极化等。这些宏观现象难以从个体行为预测，也难以评估其合理性 —— 因为我们缺乏足够的真实社会数据作为基准。

技术方案：四大架构创新

AgentSociety 针对上述三大挑战提出了四个核心技术方案，每一个都是对原始小镇架构的重要改进。

方案一：分层记忆架构

短期记忆（Working Memory）
最近的交互和当前任务上下文。容量有限，自动过期。类似人类的工作记忆，只保留当前相关的信息。成本最低，访问最快。
中期记忆（Episodic Memory）
重要事件和关键交互的结构化记录。通过重要性评分筛选，只保留超过阈值的记忆。支持语义检索，是日常决策的主要记忆来源。
长期记忆（Semantic Memory）
高度压缩的知识和长期经验。通过反思（Reflection）机制将多条中期记忆合成为抽象的知识表示。容量最大，但粒度最粗。
分层的核心意义
小镇的 Memory Stream 是一个平坦的时序日志，所有记忆存储在同一层级。在 25 Agent 规模下这没有问题，但 10,000 Agent 的记忆量会使平坦检索变得不可行。AgentSociety 的分层架构通过逐层压缩解决了这个问题：短期记忆自动过期，中期记忆定期压缩为长期记忆，确保检索空间始终可控。

方案二：异步调度

从同步到异步的范式转变

斯坦福小镇采用同步调度：每个时间步，所有 Agent 按顺序执行行动。在 10,000 Agent 规模下，同步调度意味着每个时间步需要等待所有 Agent 完成，延迟由最慢的 Agent 决定。

AgentSociety 采用异步事件驱动调度：

  • 每个 Agent 独立运行，不需要等待其他 Agent
  • 交互通过异步消息传递实现
  • 系统调度器根据 Agent 的活跃度和优先级分配计算资源
  • 不活跃的 Agent 进入「休眠」状态，不消耗 LLM 调用
调度策略对比 同步：T(step) = max(T_agent_i) × N    vs    异步：T(step) ≈ avg(T_active_agents) × 并发度

方案三：轻量推理路径

关键决策 vs 常规行动的分级处理

并非所有 Agent 行为都需要完整的 LLM 推理。AgentSociety 引入了分级推理策略：

  • 常规行动（如移动、日常对话）：使用基于规则或小模型的轻量推理路径，极大降低 LLM 调用量
  • 关键决策（如重要社交、策略选择）：使用完整的 LLM 推理 + Chain-of-Thought
  • 触发机制：系统根据情境复杂度自动判断应使用哪种推理路径
80/20 法则的应用
AgentSociety 的核心洞见是：大约 80% 的 Agent 行为是常规性的（走路、吃饭、日常寒暄），只有 20% 需要深度推理（关键决策、复杂社交）。通过将 80% 的常规行为分流到轻量路径，系统将 LLM 调用量减少了一个数量级，同时在关键决策上保持了质量。

方案四：Chain-of-Thought 集成

关键决策使用 CoT 推理保持质量

对于被判定为「关键决策」的行为，AgentSociety 使用 Chain-of-Thought 推理确保决策质量：

  • 情境分析：Agent 首先分析当前情境的关键因素
  • 记忆召回：从分层记忆中检索相关经验
  • 推理展开：通过 CoT 逐步推导决策逻辑
  • 行动生成：基于推理结果生成具体行动

这种设计确保了在大规模仿真中，质量和效率的平衡不是全局性的妥协，而是按需分配的精细控制。

关键发现

发现一：大规模社会涌现

宏观社会现象的自发形成

在万人级仿真中，系统观察到了多种仅在大规模时才出现的社会现象：

  • 社区自组织：Agent 基于共同兴趣和地理邻近性自发形成社区，社区内部形成稳定的社交网络
  • 信息传播链：信息在社交网络中的传播呈现出与真实社会类似的扩散模式（包括信息衰减和变形）
  • 集体决策涌现：在面对公共事务时，Agent 群体展现出类似民主决策的行为模式
  • 社会分层：不同 Agent 在社交网络中形成了中心-边缘的层级结构
涌现的质变点
研究发现，某些社会现象存在明确的规模阈值：例如，社区自组织在 Agent 数量超过约 500 时开始显著出现；信息瀑布效应在超过 2,000 Agent 时变得稳定。这意味着 25 Agent 的小镇仿真在原理上无法观察到这些现象 —— 规模本身是涌现的必要条件。

发现三：成本效率分析

最小可行复杂度（Minimum Viable Complexity）
AgentSociety 提出了一个重要概念：达到可接受仿真质量所需的最小 Agent 复杂度。研究发现，并非所有 Agent 都需要完整的认知架构。在万人级仿真中，只有约 10-15% 的「核心 Agent」需要完整的记忆 + 反思 + 规划能力，其余 Agent 使用简化版本即可维持整体仿真质量。这一发现对大规模部署有重大的成本意义。

对领域的意义

意义一：证明架构可扩展性

AgentSociety 最重要的贡献是实证性地证明了 Generative Agents 架构的可扩展性。在此之前，人们只能推测小镇架构能否支撑大规模仿真。AgentSociety 给出了明确答案：可以，但需要架构级别的适配（分层记忆、异步调度、分级推理）。

意义二：社会科学的新工具

前所未有的仿真规模
传统社会科学研究受限于实验规模（通常几十到几百人），且涉及伦理约束。AgentSociety 提供了一个万人级的「社会实验室」，研究者可以在其中观察社区形成、信息传播、集体决策等宏观社会现象，而无需真实人类参与。这为计算社会科学开辟了新的研究范式。

意义三：暴露扩展瓶颈

AgentSociety 也诚实地暴露了当前架构在扩展时的核心瓶颈：

记忆检索成本
随着交互积累，每个 Agent 的记忆量持续增长，检索延迟也随之增加。分层记忆缓解但未根本解决这个问题 —— 长期运行后，即使是压缩后的长期记忆也会变得庞大。
推理质量-效率权衡
轻量推理路径虽然节省了计算成本，但不可避免地牺牲了部分行为质量。系统需要精确判断何时使用轻量推理、何时使用完整推理，而这个判断本身也需要计算资源。
评估困难
如何评估万人级仿真的「质量」是一个开放问题。缺乏真实世界基准数据，难以判断涌现的社会现象是否合理。目前只能依赖定性观察和与已知社会学理论的对比。
尚未解决的核心问题

AgentSociety 暴露了一个更深层的问题：当 Agent 数量超过一定规模后，仿真结果对架构细节高度敏感。轻量推理路径的阈值设定、记忆压缩的粒度、异步调度的优先级策略 —— 这些「实现细节」会显著影响宏观涌现行为。这意味着大规模仿真的可复现性和可解释性仍是重大挑战。
