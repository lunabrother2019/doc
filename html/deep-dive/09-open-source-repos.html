Agent架构（核心参考）

Generative Agents (Stanford Smallville)
~20.7K | Python | 可运行 我们研究的起点

论文：Generative Agents: Interactive Simulacra of Human Behavior (Park et al., UIST 2023)

核心技术：Memory Stream + Recency/Importance/Relevance检索 + 阈值触发反思 + 递归日程规划 + Phaser.js沙盒环境

主要用途：Agent架构的学术标杆。包含完整的25Agent仿真环境和前端可视化。

验证重点：Memory Stream的数据结构、RIR检索实现、反思触发逻辑、规划分解代码

与半年计划关联：Phase 1 Agent循环的原型参考

ReAct
Python | 研究代码

论文：ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., ICLR 2023)

核心技术：推理(Thought) + 行动(Action) + 观察(Observation)交替循环

主要用途：Agent实时推理-行动范式的奠基工作。Claude Code的KAIROS心跳式连续规划本质上是ReAct的工程化。

验证重点：Thought/Action/Observation的交替逻辑、Prompt模板设计

LATS (Language Agent Tree Search)
Python | 研究代码

论文：Language Agent Tree Search Unifies Reasoning Acting and Planning (Zhou et al., ICML 2024)

核心技术：蒙特卡洛树搜索(MCTS) + LLM推理 + 环境反馈 + 自反思

主要用途：将规划从线性分解提升为树搜索——Agent可以"回溯"尝试不同路径

验证重点：MCTS在LLM Agent中的具体实现、搜索深度/宽度的平衡

Voyager
~6.7K | Python | 可运行

论文：Voyager: An Open-Ended Embodied Agent with LLMs (NVIDIA, 2023)

核心技术：自动课程(Automatic Curriculum) + 技能库(Skill Library) + 代码生成执行 + 自我验证

主要用途：Minecraft中的终身学习Agent，技能库不断增长。是"Agent通过积累能力越来越强"的标杆。

验证重点：技能库的存储/检索机制、自动课程如何决定下一个目标

记忆系统

A-MEM (Agentic Memory)
~935 | Python | MIT | 活跃维护

论文：A-MEM: Agentic Memory for LLM Agents (NeurIPS 2025)

核心技术：Zettelkasten卡片索引 + 动态建边 + 语义邻居关联 + Agent自主决定记忆组织方式

主要用途：从"线性记忆流"到"关联记忆网络"的范式升级。对应Claude Code的MEMORY.md指针索引思想。

验证重点：记忆节点的数据结构、边的建立/更新逻辑、检索算法

与半年计划关联：Phase 1 记忆系统v1的索引设计参考

MemoryOS
~1.3K | Python | 活跃维护 | Docker + MCP支持

论文：MemoryOS: Memory OS of AI Agent (EMNLP 2025 Oral)

核心技术：短期/中期/长期三级记忆架构 + FIFO + 分段页式管理 + 操作系统内存管理隐喻

主要用途：将OS内存管理原理应用到Agent记忆。LoCoMo基准F1提升49.11%。已支持MCP集成。

验证重点：三级记忆的调度策略、FIFO淘汰逻辑、与MCP的集成方式

与半年计划关联：Phase 1 三层记忆架构的直接参考

MemoryBank
Python | 研究代码

论文：MemoryBank: Enhancing LLMs with Long-Term Memory (AAAI 2024)

核心技术：艾宾浩斯遗忘曲线 + SiliconFriend AI陪伴 + 记忆强度衰减

主要用途：首个将认知科学遗忘曲线应用到LLM记忆的工作。

验证重点：遗忘曲线的具体实现、记忆强度计算公式

与半年计划关联：Phase 3 autoDream的Prune阶段参考

HiAgent
Python | 研究代码

论文：HiAgent: Hierarchical Working Memory Management for LLM Agents

核心技术：分层工作记忆 + 动态上下文管理 + 任务相关记忆筛选

主要用途：解决长horizon任务中的记忆管理问题。

验证重点：分层架构的具体层级、上下文裁剪策略

Letta (原MemGPT)
~21.6K | Python | 活跃维护 | 100+贡献者

论文：MemGPT: Towards LLMs as Operating Systems

核心技术：虚拟上下文管理（类OS内存页面调度）+ 自编辑记忆 + 无限对话长度

主要用途：将LLM的上下文窗口当作"RAM"管理，实现理论上无限长的对话。有商业平台。

验证重点：页面调度算法、记忆编辑机制、与向量DB的集成方式

与半年计划关联：Phase 1 上下文压缩策略的参考（对应Claude Code 5级瀑布的学术版）

反思机制

Reflexion
~3K | Python | 可运行

论文：Reflexion: Language Agents with Verbal Reinforcement Learning (Shinn et al., NeurIPS 2023)

核心技术：Actor/Evaluator/Self-Reflection三组件 + 语言RL + 滑动窗口经验缓冲

主要用途：反思演进第2阶段。Agent从失败中学习，不需要梯度更新。AlfWorld +22%, HotpotQA +20%, HumanEval 91%。

验证重点：Self-Reflection的Prompt设计、经验缓冲的滑动窗口实现、重试逻辑

与半年计划关联：Phase 3 自优化循环的基础思想来源

ExpeL
Python | 清华LeapLab | 研究代码

论文：ExpeL: LLM Agents Are Experiential Learners (AAAI 2024)

核心技术：跨任务经验提取 + 成功/失败轨迹对比 + 可迁移洞见生成

主要用途：反思演进第5阶段。从单次反思到跨任务经验积累。对应Claude Code的extractMemories。

验证重点：轨迹对比的具体实现、洞见提取的Prompt、跨任务迁移效果

Multi-Agent Debate (MAD)
Python | 研究代码

论文：Encouraging Divergent Thinking in LLMs through Multi-Agent Debate (Liang et al., EMNLP 2024)

核心技术：多LLM实例辩论 + Judge仲裁 + "思维退化"问题识别与缓解

主要用途：反思演进第4阶段。用多Agent辩论替代单Agent自我纠正，解决确认性偏差。

验证重点：辩论轮次管理、Judge的评判Prompt、与单Agent基线的对比

多Agent协调

ChatDev
~32K | Python | 活跃维护 | ChatDev 2.0 (2026.01)

论文：Communicative Agents for Software Development

核心技术：角色扮演多Agent + 瀑布流开发 + 代码评审Agent + 测试Agent

主要用途：多Agent协作开发软件的标杆。ChatDev 2.0支持零代码编排。

验证重点：Agent角色分配、Agent间对话协议、代码生成→评审→修复的循环

MetaGPT
~66.7K | Python | 活跃维护 | ICLR 2024 Oral

论文：MetaGPT: Meta Programming for Multi-Agent Collaborative Framework

核心技术：SOPs(标准作业流程)编码为Agent行为 + 结构化输出 + 角色专业化 + 全局消息池

主要用途：最高Star的多Agent框架。将软件工程的SOP转化为Agent协作流程。

验证重点：SOP到Agent行为的映射、全局消息池设计、与Claude Code Mailbox的对比

与半年计划关联：Phase 2 编排模式参考（但MetaGPT偏预设角色，我们偏自组织）

AgentVerse
~4.7K | Python | 维护中

论文：AgentVerse: Facilitating Multi-Agent Collaboration (OpenBMB/Tsinghua)

核心技术：任务求解模式 + 社会仿真模式 + 可插拔Agent设计

主要用途：同时支持"做任务"和"仿真社会"两种模式的统一框架。

验证重点：两种模式的切换机制、Agent插拔接口设计

CAMEL
~15.2K | Python | Apache 2.0 | 活跃维护

论文：CAMEL: Communicative Agents for "Mind" Exploration (NeurIPS 2023)

核心技术：角色扮演通信框架 + Inception Prompting + 任务分解

主要用途：多Agent通信的早期标杆。生态包含OWL、OASIS、CRAB等子项目。

验证重点：Inception Prompting的具体实现、Agent间消息格式

MultiAgentBench (MARBLE)
Python | 活跃 | ACL 2025

论文：MultiAgentBench: Evaluating Collaboration and Competition of LLM Agents

核心技术：里程碑式KPI + Star/Chain/Tree/Graph拓扑测试 + 认知规划策略

主要用途：首个系统评测多Agent协作与竞争的基准。graph拓扑最优，认知规划+3%。

验证重点：KPI指标的计算方式、不同拓扑的实现、可否适配到我们的业务场景

与半年计划关联：Phase 3 评测基准的直接参考

社会仿真

Concordia
~1.2K | Python (>=3.11) | PyPI可安装 | 活跃维护

来源：Google DeepMind

核心技术：Game Master架构 + 混合动机场景 + 多Agent博弈交互

主要用途：形式化LLM在社会仿真中的交互。NeurIPS 2025竞赛基础框架。

验证重点：Game Master的调度逻辑、Agent决策接口、场景定义DSL

Sotopia
~290 | Python | 活跃维护 | ICLR 2024 Spotlight

论文：SOTOPIA: Interactive Evaluation for Social Intelligence in Language Agents (CMU)

核心技术：90个场景 + 40个角色 + 社交智能多维评测（目标完成度/可信度/秘密保守等）

主要用途：Agent社交智能的评测框架。S4版支持大规模定制仿真。

验证重点：评测维度的实现、场景/角色的定义格式

AgentSociety
Python | 清华 | 活跃维护 | WWW'25挑战赛

论文：AgentSociety: Large-Scale Simulation of LLM-Driven Generative Agents

核心技术：10K+ Agent + 500万交互 + 情绪/需求/动机驱动行为 + 底层涌现社会结构

主要用途：Smallville的大规模升级版。Agent拥有"心智"（情绪+需求+动机），行为由内部状态动态驱动。

验证重点：Agent心智模型的实现、大规模调度机制、涌现行为的检测方法

SocioVerse
Python | 复旦 | 新项目

论文：SocioVerse: A World Model for Social Simulation with 10M Users

核心技术：1000万真实用户池 + User/Scenario/Behavior Engine四组件 + 政治/新闻/经济三领域

主要用途：目前规模最大的社会仿真世界模型。

验证重点：用户画像生成、行为引擎的推理链、大规模调度性能

PolicySim
Python | ACM Web 2026 | 待确认公开

论文：PolicySim: LLM-Based Agent Sandbox for Proactive Policy Optimization

核心技术：SFT+DPO微调用户Agent + 上下文赌博机 + 图消息传递 + 回音室→跨立场干预

主要用途：从"观察涌现"到"工程化干预"的范式转变。技术栈深度最高的仿真论文。

验证重点：SFT/DPO训练管道、Bandit策略实现、消息传递方程

注意：论文声明有代码，但截至检索时repo可能未公开，需持续关注

工程框架与工具（非论文，但半年计划直接使用）

LangGraph
Python + JS | LangChain | 活跃维护 | 半年计划推荐

核心技术：图状态管理 + Checkpoint/恢复 + Human-in-the-loop + 流式处理

主要用途：半年计划推荐的Agent框架。显式图状态管理最接近Claude Code的queryLoop设计。

验证重点：State Graph定义方式、Checkpoint持久化、与MCP的集成

CrewAI
~43K | Python | 活跃维护 | v1.13.0 (2026.04)

核心技术：角色/目标/背景定义 + 内置委托机制 + CrewAI Enterprise(RBAC/审计)

主要用途：快速原型首选。简单的角色定义心智模型，快速出MVP。

验证重点：Agent定义DSL、委托机制、企业版功能

AutoGen
Python | Microsoft | 维护模式 | 正合并到Semantic Kernel

核心技术：Group Chat模式 + 强类型 + AutoGen Studio可视化

注意：正在与Semantic Kernel合并为"Microsoft Agent Framework"。仅接收关键bug修复。社区fork：AG2

Mem0
Python | Apache 2.0 | 活跃维护 | 半年计划关注

核心技术：用户/会话/Agent三级记忆 + 自动事实提取 + LOCOMO基准+26%准确率

主要用途：专用Agent记忆层。可能在Phase 3替代自建autoDream。

验证重点：记忆提取的准确率、与LangGraph的集成、自托管部署难度

Graphiti (原Zep核心)
Python | 活跃维护 | Zep CE已废弃

核心技术：时序知识图谱 + 实体提取 + 事实管理 + 图遍历检索

主要用途：Agent记忆的知识图谱方案。Zep社区版已废弃，Graphiti是存活的开源核心。

验证重点：知识图谱构建方式、时序推理能力、与向量DB的互补性

LangFuse
TypeScript + Python SDK | 活跃维护 | 可自托管 | 半年计划推荐

核心技术：Agent Trace追踪 + 评测评分 + Prompt管理 + OpenTelemetry兼容

主要用途：半年计划推荐的可观测性方案。可自托管满足数据驻留要求。

验证重点：Trace粒度、评测管道配置、自托管部署流程
