BiLLP：双层规划（Macro + Micro）

SIGIR 2024。核心洞察：LLM 在 sparse data 环境下的 planning 能力远优于从零训练的 RL。

BiLLP 双层结构 Macro-Learning (LLM): 输入: 用户交互历史 + 反思 输出: 宏观策略 (e.g., "引导用户从探索走向深度消费") Micro-Learning (Actor-Critic): 输入: 宏观策略 + 当前上下文 输出: 具体推荐动作 + Q-value 估计

这精确对应小镇的 hierarchical planning——high-level daily plan 分解为 hourly action sequences。BiLLP 在 KuaiRand / ML-1M 上显著优于 RL baseline（DORL / CIRS）。

代码：github.com/jizhi-zhang/BiLLP

3

AFL：双 Agent 反馈闭环

SIGIR 2025。将 Recommendation Agent 和 User Agent 放入迭代循环：

1
Rec Agent 推荐 — 基于对用户偏好的理解，给出 item 列表 + 推荐理由
2
User Agent 反馈 — 分析推荐结果，给出接受/拒绝/原因，可能发现新兴趣
3
Rec Agent 修正 — 根据 feedback 更新偏好理解，改进下一轮推荐
4
迭代 — 循环多轮，双方共演化
关键结果
  • 比单独 Rec Agent：平均 +11.52%
  • 比单独 User Agent：平均 +21.12%
  • 不加剧 popularity bias 和 position bias

AFL 的闭环直接映射 Generative Agents 中的 memory stream + reflection：每轮 feedback = memory 写入；双方对 feedback 的分析 = reflection 产生 insight。

代码：github.com/Lanyu0303/AFL

RecoWorld：验证环境蓝图

WWW Companion 2026 (HCRS Workshop)。Meta 团队。Position paper——设计蓝图而非完整实现。

双视角架构

  • Simulated User：审阅推荐内容 → 更新 mindset → 感知脱离风险 → 生成 reflective instructions
  • Agentic Recommender：接收 instructions → 调整策略 → 最大化 user retention

关键设计

  • Multi-agent population simulation — 多用户群体仿真（呼应 OASIS 的百万 Agent 路线）
  • Creator experimentation — 内容创作者也是 Agent，形成三方博弈
  • Content representation — 探索 text-based / multimodal / semantic ID 三种表示
  • Multi-turn RL training — 在仿真环境中用 RL 训练推荐策略
为什么 RecoWorld 是 Validation Gap 的最直接解法

RecoWorld 的设计目标是：一个 Gym-like RL 环境，其中 LLM user simulator 替代真人做 A/B 测试。如果这个环境的 user simulator 行为与真人行为分布一致（可通过历史数据验证），则仿真结果就有科学可信度。这正是 challenge/validation-gap.html 提出的"推荐系统是最接近完美的验证场"的论据。
