自动驾驶：DriveMLM + Multi-Agent Survey

DriveMLM（上海 AI Lab，Visual Intelligence 2025）

将多模态 LLM 嵌入模块化自动驾驶系统（Apollo/Autopilot）作为 plug-and-play 行为规划模块。用标准化 decision states 桥接语言决策与车辆控制指令。CARLA Town05 Long benchmark 上 Driving Score 提升 3.2–4.7 分。

Multi-Agent AD Survey（EMNLP 2025 Findings）

首篇 LLM 多 Agent 自动驾驶综述。核心发现：多 Agent 协作可扩展感知范围（遮挡检测）、提升实时协调（merge/roundabout）、分布式计算降低单体负载。

DriveMLM 的"感知→推理→决策→解释"循环与小镇的 Perceive→Plan→Act 高度同构；Multi-Agent Survey 则是把小镇的 25 Agent 社会协作范式搬到了物理道路——每辆车是一个 Agent，路口是"社交场景"。
2

游戏 NPC：跨平台对话 + Ubisoft Teammates

LLM-Driven NPCs（arXiv:2504.13928）

用 DeepSeek-R1 驱动 Unity 游戏内 NPC，同时通过 Discord 与玩家对话；LeanCloud 同步 memory。发现 memory dilution 问题——超过 20 轮对话后记忆衰减，建议引入 RAG/vector database。这正是小镇用 recency×importance×relevance 公式解决的问题。

Ubisoft Teammates（2025.11，La Forge R&D）

商业级工业落地。Snowdrop 引擎 + Google Gemini + 自研 middleware。核心设计：

  • Behavior tree = 约束 action space（"能做什么"）
  • LLM layer = planning/reflection（"何时/如何做"）
  • Voice input = 人类直接注入 perception stream
  • API 安全护栏 = 过滤 hallucination / toxic / lore-breaking 输出
  • Personality sheet + fences = 编剧定义 persona 边界，NPC 在围栏内即兴
Teammates 的设计哲学
把小镇的"完全自主 Agent"收缩为"行为树约束下的有限自主"——因为商业游戏不能容忍 NPC 做出不合剧情的行为。这是 Generative Agents 从研究原型到商业产品的关键妥协。
3

经济学：GenAI as Economic Agents

Microsoft Research（Immorlica, Lucier, Slivkins），ACM SIGecom Exchanges 2024。

Position paper，核心主张：不要把 AI 只当工具，要把它建模为经济行动者。每个 user 配一个 AI agent，双方信息和偏好可能不同，产生与无 AI 场景质性不同的博弈均衡。

小镇已展现 Agent 的 emergent social behavior（投票、信息传播）。这篇论文将这种"AI 作为自主行动者"的视角正式化为经济学理论框架——如果 Smallville 的 NPC 进入市场交易，均衡会如何改变？这和 MMOAgent (DD56) 的实证发现互补：理论框架 × 游戏内实验。
4

医疗教育：GenAI Simulation-Based Education

NUS + 多机构，Clinical Simulation in Nursing 2025。Scoping review，28 篇文献（2023-2025），覆盖医学(14)与护理(10)。

GPT 模型最常用于 simulated patient portrayal（虚拟标准化病人）和 automated feedback。学习者因 psychological safety（不怕在 AI 前犯错）和 realism 倾向 GenAI 模拟。

虚拟病人模拟 = Generative Agents 在医疗的特化：需要 persona consistency（同一个"病人"前后一致）、memory continuity（记住之前说过的症状）、realistic interaction。与 DD47 AIPatient 互补：AIPatient 做诊断准确率，本综述关注教育场景的用户体验。

📌 一句话记住
小镇的 Perceive→Plan→Act 范式已扩散到自动驾驶（DriveMLM）、FPS 队友（Ubisoft Teammates）、经济博弈（MSR position paper）、医疗教育（虚拟病人）、跨平台 NPC（Discord+Unity）。每个领域只需要小镇架构的子集——游戏 NPC 要 persona+planning，自动驾驶要 perception+planning，医疗要 memory+persona。没有一个领域需要小镇的全部五根柱子。
