AgentCF：用户和物品都是 Agent

RUC GSAI (Wayne Xin Zhao, Ji-Rong Wen) + WeChat + UCSD (Julian McAuley)。WWW 2024。

核心创新：Collaborative Reflection

不只用户是 Agent——物品也是 Agent。交互后，双方协同反思：

1
预测 — User Agent 和 Item Agent 各自预测"会不会互动"
2
对比 — 与真实交互记录比较，发现预测偏差
3
协同反思 — 双方 Agent 分析差异原因，更新各自 memory description
4
传播 — 更新后的偏好传播到后续交互的其他 Agent（隐式 CF）
为什么这很激进
传统 CF 用 gradient descent 更新 embedding；AgentCF 用"语义梯度"——LLM 用自然语言反思差异并调整描述。这等于用 reflection 替代了 backpropagation。

关键发现：协同反思显著优于单侧 self-reflection（ablation 验证）；在 sparse data 场景效果尤为突出——正是 LLM 推理能力补偿数据稀疏的体现。

AgentCF++ (SIGIR 2025, 复旦+MSRA)

在 AgentCF 基础上解决跨域推荐：

  • Dual-layer memory：domain-specific memory + cross-domain memory
  • Interest group shared memory：捕获流行度对相似兴趣用户的影响
  • 在 Amazon 跨域数据集上全面提升，缓解 cold-start

代码：github.com/jhliu0807/AgentCF-plus

与小镇的深层映射

Agent4Rec 是小镇最忠实的推荐领域"克隆"——Profile/Memory/Action 三模块一一对应，emotion-driven reflection 直接继承 importance-threshold 触发机制。

AgentCF 则做了小镇没做的事：让环境中的物体也变成 Agent（物品有自己的"身份感知"和"自我理解"）���这暗示了一种小镇的可能扩展方向——如果 Smallville 里的建筑、商品、事件也是 Agent 呢？

AgentCF++ 的 group-shared memory 引入了小镇没有的社会层记忆——不只是个人记住自己的经历，而是群体共享关于流行趋势的集体记忆���这对应社会学中的"集体记忆"概念。
📌 一句话记住
Agent4Rec = 小镇克隆到推荐系统（情绪反思 + 1000 Agent + KS 验证通过）；AgentCF = 把物品也变成 Agent，用协同反思替代 gradient descent；AgentCF++ = 加入跨域共享记忆和兴趣组。三者共同证明小镇的 memory/reflection 架构在推荐领域有定量可验证的价值。
