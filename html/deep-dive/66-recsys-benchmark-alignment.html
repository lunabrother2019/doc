2

UserMirrorer：微调替代 Prompting

NTU + ZJU + SUTD（Tianjun Wei 等），ACL 2026 Main。

两阶段数据构造

  • Phase 1：强 LLM (teacher) 为用户反馈样本生成决策推理链（rationale），减少隐式信号的歧义
  • Phase 2：通过 uncertainty estimation + behavior sampling 筛选最有信息量的去噪样本

然后用筛选后的数据 SFT + DPO 微调轻量 LLM 作为 user simulator。核心创新是 hard sample mining——选择弱模型出错的 scenario 做 preference alignment。

为什么这很重要
所有 frozen-LLM simulator（RecAgent、Agent4Rec、OASIS）都受限于 LLM 本身的偏差（善良偏差/热门偏差）。UserMirrorer 用真实行为数据微调，从根本上绕过了 L1 偏差问题——simulator 不再是"LLM 假装是用户"，而是"被用户行为训练过的 LLM"。和 FireAct/AgentTuning (DD61) 思路一致但专用于推荐。

8 个 domain 的 unified scene format，约 10K 高质量样本即达最优。开源了数据集 + 微调权重 + 完整框架。

3

OmniBehavior：暴露所有 Simulator 的三大偏差

中科院 + 快手（Jiawei Chen 等），2026.04。

三大 LLM Simulator 失败模式
  1. Hyper-activity — LLM 生成的行为量比真人多（高估 engagement）
  2. Persona homogenization — 不同"用户"的行为趋同，丧失个体差异
  3. Utopian bias — 正面行为偏多，负面/冷门行为被压制

Benchmark 构成

200 名快手真实用户 × 90 天 × 6 场景（短视频/直播/购物/广告/客服/搜索）的完整行为轨迹。这是目前最全面的真实用户行为评测集。

关键发现

  • 扩展 context window 不能修复结构性偏差——更多上下文不等于更准
  • Agent4Rec 发现的"善良偏差"是 Utopian bias 的子集
  • Persona homogenization 对应我们 L2 闭环分析中"偏差可能发散"的一个机制——Agent 行为趋同 → 推荐系统学到单一模式 → 推荐更加同质化 → 正反馈
OmniBehavior 的三大偏差和小镇的"涌现多样性"形成对照：小镇 25 人涌现了派对/选举/浪漫等多样行为，但那是因为 persona 是手写的多样化种子。当 persona 从真实数据来（LLM 推断），多样性反而坍塌了。这暗示小镇的行为多样性可能是 persona 设计的产物而非 LLM 的涌现能力。
4

TriRec：三方 Agent 博弈

USTC + NUS（何向南团队），2026.03。与 AFL/BiLLP 同一研究组。

两阶段三方架构

  • Stage 1 — Item Agent 自我推广：每个 item 生成针对特定用户的个性化推广描述，改善匹配和冷启动
  • Stage 2 — Platform Agent 公平排序：多目标 sequential re-ranking，平衡用户相关性 + item 效用 + 曝光公平性
突破 user-centric 范式
之前所有 Agent 推荐系统（InteRecAgent/RecMind/AgentCF）只建模用户。TriRec 赋予 item 主动性——物品不再是被动的被推荐对象，而是有"自我营销意识"的 Agent。Platform Agent 则在用户和 item 之间做仲裁。结果：accuracy (NDCG/MRR) 和 fairness (DGU/MGU) 同时提升——打破了"精度 vs 公平"的假设权衡。

对复现计划的直接影响

我们的难题这三篇的贡献行动
L1 单步偏差UserMirrorer 用 SFT/DPO 从根本上绕过；OmniBehavior 给出偏差的精确分类用 UserMirrorer 替代 frozen-LLM 做 simulator
L2 闭环稳定性OmniBehavior 的 persona homogenization 可能是发散机制之一在 L2 实验中加 homogenization 度量
L3 A/B 等价SimUSER (DD65) 有 A/B 验证方法论；UserMirrorer 提供更准的 simulatorUserMirrorer simulator + KuaiRand 数据做 A/B 方向预测
多方公平性TriRec 证明三方 Agent 可同时提升精度和公平可选扩展方向
📌 核心判断

UserMirrorer 可能是我们复现计划中最该优先集成的工作——它直接解决 L1（用微调替代 prompting 消除偏差），为 L2（微调后的 simulator 闭环是否更稳定？）和 L3（更准的 simulator 做 A/B 预测是否更可靠？）提供基础。OmniBehavior 是验证标尺，TriRec 是可选的公平性扩展。
