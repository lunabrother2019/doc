同一问题，两条路线

共同问题
MMO 游戏的经济系统设计（物品定价、交易规则、资源投放）需要大规模用户测试，但真实 A/B 测试昂贵且有风险（破坏玩家体验）。能否用 LLM Agent 替代真人做离线仿真？
路线 A：MMOAgent（网易伏羲）

Smallville 式认知架构 + 通用 LLM (GPT-3.5) + P2P 社交涌现。追求行为自然性和角色分工涌现。KDD 2025。

路线 B：Beyond Playtesting（腾讯光子）

SFT + RL 微调 Qwen2.5-1.5B 小模型 + 数值干预测试。追求预测精度和因果推断。Preprint 2025.12。

MMOAgent：Smallville 式认知架构入 MMO

五模块架构（直接继承小镇）

P
Profile — 基于真实玩家数据 k-means 聚类生成角色画像（非手写 persona）
O
Perception — 将游戏数值状态转为自然语言描述
M
Memory — 双层：Short-Term（最近 10 条 ⟨obs, action⟩）+ Long-Term（importance scoring + Ebbinghaus 遗忘曲线衰减）
R
Reasoning — Chain-of-Thought + execution feedback loop
A
Action — 五类经济活动：Task（生产）/ Upgrade（消费）/ Auction（拍卖）/ Shop（购买）/ Recharge（充值）

关键创新

  • Numeric-aware Memory：Long-Term Memory 用 max relative difference（而非 cosine similarity）做 importance scoring——因为游戏状态是数值而非文本
  • Ebbinghaus Forgetting Curve：比小镇的 exponential recency decay 更有认知科学依据
  • P2P Trading + Chat：Agent 通过公聊/私聊谈判，涌现角色分工（富玩家→商人，穷玩家→打工者）

Beyond Playtesting：SFT+RL 微调路线

三阶段训练管线

1
Stage 1: Vocabulary SFT — LoRA (rank=16) 让 Qwen2.5-1.5B 理解游戏术语（武器名/货币名/地图名等）
2
Stage 2: Action Planning SFT — 从真实玩家日志学预测下一步动作（offline/battle/buy/sell），监督微调
3
Stage 3: GRPO Reinforcement Learning — 强化推理一致性，让 Agent 的 decision chain 更 coherent

关键设计差异

  • 无 memory / 无 reflection — 靠 SFT 把行为模式"烤进"模型参数
  • 小模型路线 — Qwen2.5-1.5B（约 GPT-3.5 1/100 参数量），推理成本极低
  • Data-driven Battle Server — 用真实对战日志训分类/回归模型预测胜负
  • 因果干预测试 — 引入官方黑市后观察非正式交易变化

核心对照：两条路线的哲学差异

维度MMOAgent (网易 · KDD 2025)Beyond Playtesting (腾讯 · 2025.12)
LLM 使用方式通用 LLM (GPT-3.5) 做 role-playing微调小模型 (Qwen2.5-1.5B) 做 prediction
认知架构Profile + Perception + Memory + Reasoning + Action无显式认知模块，行为"烤进"参数
记忆系统双层 + Ebbinghaus 遗忘曲线无（靠 SFT 隐式记忆）
社交交互P2P 交易谈判 + 聊天，涌现角色分工几乎无 Agent 间通信
核心追求行为自然性 + 社会涌现预测精度 + 因果干预
验证标准多样性 entropy / 供需 correlationAction accuracy / 干预响应合理性
规模30 Agent × 200 steps数百 Agent × 数周
推理成本高（每步调 GPT-3.5）低（1.5B 本地推理）
代码未开源（网易内部数据）未开源（腾讯内部数据）
学术贡献证明 Smallville 架构可迁移到经济仿真证明 SFT+RL 路线在 action prediction 上超越通用 LLM
两条路线的本质分歧

MMOAgent 相信：Agent 的行为应该从认知过程中涌现——给它记忆和推理能力，行为自然就像人。这是 Smallville 的哲学。

Beyond Playtesting 相信：Agent 的行为应该从真实数据中学习——用人类行为轨迹微调模型，直接模仿行为模式。这是 behavioral cloning 的哲学。

两者分歧的根源：你相信"理解产生行为"还是"模仿即理解"？

MMOAgent 是小镇架构的忠实继承者——保留了 memory + perception + reasoning 的完整认知栈，只是把环境从物理小镇换成了 MMO 经济。Beyond Playtesting 则代表了一种后小镇路线——认为认知架构是不必要的开销，用 SFT+RL 直接从数据中学行为模式。两者的成功都证明了 LLM 在 MMO 仿真中的可行性，但解决的是不同的子问题：前者解"行为为什么"，后者解"行为是什么"。

验证试验田：MMO 的独特价值

为什么 MMO 是好的验证场
  • 完整数据闭环 — 所有玩家行为都被服务器记录，Ground Truth 完备
  • 经济系统有理论基础 — 供需/通胀/交易量有经济学分析工具
  • 支持干预实验 — 可以在仿真中"引入黑市"然后观察反应，再和真实数据比
  • 规模适中 — 比社交媒体小（万人级），比小镇大（30+ Agent），恰好在可控范围

两篇论文共同证明：MMO 经济系统是 Agent 仿真从"讲故事"走向"做预测"的可行验证场。推荐系统验证"品味像不像人"（RecAgent），MMO 验证"决策像不像人"——后者对小镇式认知架构的要求更高。

📌 一句话记住
MMO 仿真双路线：网易用 Smallville 式认知架构做社交涌现（KDD 2025），腾讯用 SFT+RL 微调做数值预测——前者证明记忆是核心，后者证明小模型+数据可超越通用 LLM。两者共同证明 MMO 是 Agent 仿真的高价值验证场。
