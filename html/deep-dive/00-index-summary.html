从小镇到 2026：五条关键发展脉络

  • 规模爆炸：25 人 (2023.04) → 1,000 人 (2024.11) → 10,000 人 (2025.02) → 10,000,000 人 (2025.04)。每 12 个月规模增长 3 个数量级。
  • 记忆从 append-only 到专业化：小镇的 memory stream 是"什么都扔进去"；后续分化为 Zettelkasten 建链 (A-MEM)、OS 调度 (MemoryOS)、生产 SDK (Mem0)、POMDP 理论化，最终 V3 Mem0 用实测证明 append-only 仍是最安全的写策略。
  • 反思从万能药到有条件工具：Reflexion (2023.03) 引爆"自我反思"热潮 → Self-Correct (2023.10) 泼冷水证明无外部信号则无效 → Sweet&Sour (2024.11) 证明正向经验同样重要 → ERL (2026) 把经验从文本升级为可检索的启发式池。
  • 从学术原型到工程落地：MetaGPT/ChatDev (2023) 是学术 demo → LangGraph/AgentScope (2025) 是生产框架 → A2A (2025-2026) 是跨厂商互操作标准。三年内从"能跑"到"能部署"到"能互通"。
  • 评估从定性到定量：小镇靠"情人节派对真的发生了"定性评估 → SOTOPIA 7 维量表 (2023.10) → LOCOMO 长对话 benchmark → StructMemEval 结构对比 → Terminal-Bench 工业验证。评估基础设施的成熟度决定了整个领域的可信度。

尚未覆盖的潜在缺口

  • 安全与对齐：53 篇中仅 Abliteration (04) 和 Critical Perspectives (36) 涉及安全面。随着 Agent 能力增强，对齐研究（如 Constitutional AI for Agents）是明显空白。
  • 经济激励 / 博弈论：社会仿真大多假设 Agent 是"善意"的；缺少带博弈论动机的 Agent（如拍卖、欺骗、策略性信息隐藏）。
  • 持续学习（Continual Learning）：Voyager 的 skill library 是一种形式，但真正的 catastrophic forgetting 问题在 Agent 记忆领域还没有被严肃对待。
  • 多模态 Agent：GEA (29) 涉及具身多模态，但纯视觉/音频 Agent 的记忆和反思几乎未被覆盖。
  • 真实世界部署后的 longitudinal study：所有论文都是"实验室时间尺度"（几天到几周），缺少 Agent 持续运行数月后的退化/漂移分析。
