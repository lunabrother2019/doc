三大范式

范式核心思想代表工作与小镇的距离
Recommender-oriented
推荐导向		 Agent 直接增强推荐机制（planning / reasoning / tool-use 提升推荐质量） RecMind, MACRec, BiLLP, ToolRec 中——用了 planning 和 tool use
Interaction-oriented
交互导向		 通过自然对话实现可解释推荐（human-like dialogue + 推荐理由透明化） InteRecAgent, MACRS, RecLLM 中——用了 memory 和 reflection
Simulation-oriented
仿真导向		 Multi-agent 模拟真实用户行为与系统动态 Agent4Rec, RecAgent, AgentCF, OASIS 最近——完整继承 Smallville 架构
Simulation-oriented = Smallville 在推荐领域的落地
综述明确引用 Park et al. (2023) Generative Agents 作为 simulation-oriented 范式的基础工作。该范式下分三个子方向：User Behavior Simulation（Agent4Rec/RecAgent）、Collaborative Agent Simulation（AgentCF）、System Dynamics Simulation（AFL/RecoWorld）。

统一架构：Profile / Memory / Planning / Action

模块功能推荐系统实例Smallville 对应
Profile构建动态用户/物品表征Agent4Rec 融合 activity/conformity/diversity 三维社交特质Persona (seed memory)
Memory管理历史交互与情感记忆RecAgent 三层记忆；AgentCF dual-layerMemory Stream
Planning制定多步推荐策略BiLLP macro/micro 分层；RecMind Self-InspiringDaily plan → hourly actions
Action执行推荐并捕获反馈RecAgent 六种行动模态（搜索/浏览/点击/翻页/聊天/广播）Agent 物理动作

综述的独特贡献：显式对齐推荐系统 Agent 与 Generative Agents 的四模块架构。这为跨领域迁移提供了方法论框架——任何新垂直领域要做 Agent 仿真，都可以按 Profile/Memory/Planning/Action 四件套来设计。

3

Simulation-oriented 的挑战

综述指出该范式面临的核心问题：

  • 评估标准缺失 — "Agent 行为像不像真人"缺乏统一 benchmark（对应我们的 验证鸿沟）
  • 可扩展性 — 1000 Agent × 多轮交互的 LLM 成本仍然昂贵
  • 对抗攻击脆弱性 — 论文提到 CheatAgent：恶意 Agent 可通过操控 profile 欺骗推荐系统
  • LLM 偏差传播 — position bias / popularity bias 从 LLM 传导到仿真结果
这篇综述是目前唯一一篇系统性对齐 Smallville 架构与推荐系统 Agent 的工作。它证实了我们在 challenge/verification-testbeds.html 中的判断：推荐系统是 Generative Agents 范式获得定量验证的最佳突破口——因为行为数据密度最高、feedback 循环最快、评估指标最成熟。
4

覆盖规模与评估基础设施

  • 覆盖方法：30+ 种
  • Benchmark 数据集：Amazon Books (1030万用户) / MovieLens-1M/20M / Steam / Yelp / ReDial / OpenDialKG
  • 评估指标：NDCG@K / Recall@K / BLEU/ROUGE / Agent memory believability
