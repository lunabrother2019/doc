核心论点：Smallville 埋下了什么种子

Park et al. 2023 年的论文做了一件看似简单的事：给 25 个 LLM Agent 各自配上记忆、反思、规划三个模块，然后放进一个沙盒小镇里让它们自由运行。论文的核心发现不是这些模块本身，而是涌现——Agent 自发组织了情人节派对、建立了社交关系、传播了信息。

这个发现看上去像一篇 demo 论文，但它实际上提出了一个深刻的问题：

如果给 LLM Agent 足够的认知架构（记忆+反思+规划）和交互空间，复杂的社会行为是否会自发涌现？涌现的边界在哪里？可以被工程化控制吗？

2025-2026 年的多 Agent 论文几乎都在回答这个问题的某个侧面。我把它们归为六个方向：

Smallville 2023
观察涌现 → 博弈论分析
解释涌现 → 自组织研究
量化涌现 → 规范与协议
约束涌现 → 共同进化
工程化涌现
1

涌现合作与博弈论分析

Smallville 观察到了涌现的合作行为（派对组织、信息传播），但没有解释为什么会合作。2025-2026 年的一批论文用博弈论框架回答了这个问题。

The Yerkes-Dodson Curve for AI Agents: Emergent Cooperation Under Environmental Pressure
2026.03 · arXiv
Stress-Performance Inverted-U Environmental Pressure Grid-world Survival Arena Resource Scarcity

首次系统研究 LLM 多 Agent 系统中的压力-绩效关系。在生存场景中调整环境压力（资源稀缺度），发现合作行为遵循倒 U 形曲线：中等压力下交易互动最多（29 次），压力过低（无需合作）或过高（忙于生存）都会降低合作。

Smallville 的环境压力接近零（和平小镇），所以观察到的合作是"社交驱动"的。这篇论文揭示了另一种合作来源——生存压力驱动。暗示 Smallville 如果加入资源竞争，涌现行为可能完全不同。
Understanding LLM Agent Behaviours via Game Theory: Strategy Recognition, Biases and Multi-Agent Dynamics
2025.12 · arXiv
Prisoner's Dilemma Public Goods Game End-game Defection Cross-linguistic Divergence

用囚徒困境和公共品博弈系统评估 LLM Agent 的策略行为。关键发现：(1) 所有模型在终局都趋向背叛；(2) 不同语言下 Agent 策略显著不同（文化偏差嵌入在训练数据中）；(3) 激励强度影响合作意愿。

Smallville 的 Agent 全部使用英语、同一个 LLM（ChatGPT）。这篇论文表明如果用不同语言/不同模型初始化 Agent，涌现出的社会结构可能截然不同——这是 Smallville 未曾探索的维度。
Competition and Cooperation of LLM Agents in Games
2026.04 · arXiv
Multi-round Cooperation Fairness Reasoning Non-zero-sum Context

发现 LLM Agent 在多轮非零和博弈中倾向合作，且公平推理是驱动合作的核心机制——Agent 不是因为"利益最大化"合作，而是因为"觉得应该公平"。

这解释了 Smallville 中为什么 Agent 会"邀请所有人"参加派对而不是只邀请亲密朋友——LLM 内置的公平偏好驱动了包容性的社交行为。这不是"涌现"，而是训练数据中的价值观泄漏。
Will Systems of LLM Agents Cooperate: An Investigation into a Social Dilemma
2025.01 · arXiv
Evolutionary Game Theory Strategic Dispositions Population Dynamics

用演化博弈论模拟 LLM Agent 群体的策略演化。不同 LLM 表现出不同的策略偏好——有的偏攻击性，有的偏合作。群体中策略的成功取决于群体组成而非个体能力。

Smallville 用同一个模型，所以所有 Agent 的"性格底色"相同。这篇论文指出：如果用异构模型构建 Agent 社会，群体动态会更丰富——这是 AgentSociety 等后续工作已经在做的事。
2

自组织与涌现分工

Smallville 预设了每个 Agent 的角色（药剂师、教授、学生）。但如果不预设角色，Agent 能自发分工吗？这是 2025-2026 年最重要的发现之一。

Drop the Hierarchy and Roles: How Self-Organizing LLM Agents Outperform Designed Structures
2026.03 · arXiv
Endogeneity Paradox Emergent Specialization 25,000 Task Runs 4-256 Agents 5,006 Unique Roles

本领域最重要的实证论文之一。超过 25,000 次任务运行，跨 8 个模型、4-256 个 Agent、8 种协议。核心发现——内生性悖论：最优协调不来自最大控制，也不来自最大自治，而来自最小结构脚手架 + 完全角色自治的混合体。

8 个 Agent 自发产生了 5,006 个独特角色。系统可以亚线性扩展到 256 个 Agent 而质量不下降。

这篇论文直接挑战了 Smallville 的设计：Park 为每个 Agent 预设了身份和人设（"Isabella 是咖啡店老板"），但这可能是多余的。给 Agent 最小的结构约束，让它们自己决定"我是谁"，产出反而更好。这意味着 Smallville 的"角色预设"可能限制了涌现的潜力。
Emergent Coordination in Multi-Agent Language Models
2025.10 · arXiv (updated 2026.03)
Dynamical Emergence Cross-agent Synergy Prompt Steering

测量多 Agent LLM 系统中是否存在动态涌现（而不仅是统计巧合）。通过 Prompt 设计，可以将 Agent 从"独立个体"引导为"高阶集体"。区分了虚假的时序耦合和真正的跨 Agent 协同。

Smallville 声称观察到了"涌现"，但没有严格区分这是真正的跨 Agent 协同还是各自独立决策恰好看起来协调。这篇论文提供了科学验证涌现的方法论——Smallville 的后续研究需要这种严谨性。
OrgAgent: Organize Your Multi-Agent System like a Company
2026.04 · arXiv
Organizational Structure Company Metaphor Structural Forms

将组织管理学引入多 Agent 系统：不同组织结构（扁平/层级/矩阵）如何影响 Agent 的协调效率和专业化程度。

Smallville 的 25 个 Agent 是扁平结构，没有层级。这篇论文提示：如果引入组织结构（比如让某个 Agent 成为"镇长"），可能会产生完全不同的社会动态。
3

社会规范与集体智能

Smallville 的 Agent 没有显式的"社会规范"——它们的行为完全由个体的记忆/反思/规划驱动。但在更大规模的仿真中，规范会自发形成吗？

The Role of Social Learning and Collective Norm Formation in Fostering Cooperation in LLM Multi-Agent Systems
2025.10 · arXiv
Social Learning Collective Norm Formation Normative Reasoning

研究 LLM Agent 能否通过社会学习形成集体规范。在虚拟社会和博弈论环境中，Agent 通过观察他人行为逐渐形成共享的行为规范，且这些规范反过来促进合作。

Smallville 中 Agent 的"规范"其实是 Prompt 预设的（"你是一个友善的人"）。这篇论文展示了规范可以从底层交互中自发涌现——这是比 Smallville 更深层次的涌现。
On the Dynamics of Multi-Agent LLM Communities Driven by Value Diversity
2025.12 · arXiv
Value Diversity Heterogeneous > Homogeneous Collective Intelligence

关键发现：价值观异质的 Agent 群体在集体智能上显著优于同质群体。多样性带来更多涌现性问题解决和规范发展。

Smallville 的 25 个 Agent 由同一个 LLM 驱动，本质上是价值观同质的（都继承了 ChatGPT 的价值取向）。这篇论文暗示：Smallville 如果用不同价值观的模型驱动不同 Agent，涌现的社会结构会更丰富、更接近真实社会。
Beyond Static Responses: Multi-Agent LLM Systems as a New Paradigm for Social Science Research
2025.06 · arXiv
Complex Adaptive Systems Artificial Leviathan Cultural Evolution Institutional Change

提出多 Agent LLM 系统作为社会科学研究的新范式。最高级别（Level 5）是复杂自适应系统：自组织、规范形成、系统性适应。Artificial Leviathan 框架探索合作规范和治理结构的涌现——Agent 从竞争逐渐演化为有组织的合作社会。

这篇论文将 Smallville 定位为 Level 2-3 的工作（单环境多 Agent 交互），并指出了通向 Level 5（文化演化、制度变迁）的路径。Smallville 是起点，不是终点。
AI Agent Behavioral Science
2025.06 · arXiv
Agent Behavioral Science Cognitive Biases in LLM Agents

提出将行为科学方法系统应用于 AI Agent 研究：量化 Agent 的认知偏差、社会偏好、决策模式。

Smallville 的评估主要靠人类评审打分（"这个行为看起来像人吗"）。这篇论文提供了科学的评估框架，可以定量分析 Smallville Agent 的认知偏差和社会偏好。
4

通信协议与编排标准

Smallville 的 Agent 通过自然语言对话交互，没有结构化的通信协议。当 Agent 数量从 25 扩展到 10,000+，这种方式无法持续。

The Orchestration of Multi-Agent Systems: Architectures, Protocols, and Enterprise Adoption
2026.01 · arXiv
MCP / A2A / ACP / ANP Enterprise Orchestration Architecture Taxonomy

系统梳理多 Agent 编排的架构、协议和企业落地。覆盖 MCP（Anthropic）、A2A（Google）、ACP、ANP 等标准，以及 SAFEFLOW 等安全增强框架。

Smallville 的通信是"两个 Agent 碰面就聊天"，这种设计无法工程化。本文梳理的协议栈是从 Smallville 走向生产级多 Agent 系统的必经之路。
AgentOrchestra: Orchestrating Hierarchical Multi-Agent Intelligence with the TEA Protocol
2025.06 · arXiv
TEA Protocol Tool-Environment-Agent Hierarchical Orchestration

提出 TEA（Tool-Environment-Agent）协议，将工具、环境和 Agent 三者的关系标准化，实现层级式多 Agent 编排。

Smallville 的沙盒环境是硬编码的 Phaser.js 游戏地图。TEA 协议提供了一种通用方式来定义 Agent-环境交互，使 Smallville 式的仿真可以在任意环境中运行。
AgentsNet: Coordination and Collaborative Reasoning in Multi-Agent LLMs
2025.07 · arXiv
100 Agents Scaling Collaborative Reasoning

可扩展到 100 个 Agent 的协调推理框架，且能随 LLM 新一代模型升级而提升。

Smallville 的 25 个 Agent 是硬上限。AgentsNet 展示了在保持协调质量的前提下扩展 Agent 数量的工程路径。
Towards Adaptive, Scalable, and Robust Coordination: A Dynamic Ad-Hoc Networking Perspective
2026.02 · arXiv
Ad-Hoc Networking Dynamic Topology Adaptive Coordination

借鉴移动自组网（MANET）的思想：Agent 动态加入/退出，网络拓扑实时变化，协调机制自适应。

Smallville 的 25 个 Agent 是静态集合，不会有人"搬走"或"新搬来"。现实社会是流动的——这篇论文解决了动态社会的工程基础。

多 Agent 评测基准

Smallville 的评估方式是让人类评审判断 Agent 行为"是否像人"——这太主观了。新的评测基准试图让评估变得科学。

MultiAgentBench (MARBLE): Evaluating the Collaboration and Competition of LLM Agents
2025.03 · ACL 2025
Milestone-based KPI Collaboration + Competition Star/Chain/Tree/Graph Topologies Cognitive Planning

首个系统评测多 Agent 协作与竞争的基准。使用里程碑式 KPI（而非仅任务完成率）评估协作质量。测试了 star/chain/tree/graph 四种拓扑和认知规划等策略。发现 graph 结构最优，认知规划提升里程碑达成率 3%。

Smallville 没有结构化评测——只知道"Agent 办了派对"但不知道协作效率如何。MARBLE 提供了量化多 Agent 协作质量的标准方法，可以回答"25 个 Agent 的协作到底有多好"。
Evaluation and Benchmarking of LLM Agents: A Survey
2025.07 · arXiv
Agent Evaluation Taxonomy Multi-Agent Metrics

Agent 评测方法的综述：单 Agent 能力评测、多 Agent 协作评测、端到端任务评测三个层次。

为 Smallville 类系统的评估提供了方法论框架。
LLM Collaboration With Multi-Agent Reinforcement Learning
2025.08 · arXiv
MAGRPO Emergent Cooperation Schemes Multi-Agent RL Fine-tuning

用多 Agent 强化学习（MAGRPO）微调 LLM，使 Agent 在最小约束下自发涌现多样的合作方案。不预设合作模式，让 RL 训练自动发现最优协作策略。

Smallville 的合作完全靠 Prompt + 记忆/反思驱动（零训练）。这篇论文展示了用RL 训练可以让合作更高效——这是 Smallville 架构的一个自然升级方向。
6

共同进化与自我改进

Smallville 的 Agent 不会"变聪明"——运行 100 天后，它们的认知能力和第 1 天完全一样（LLM 参数没变）。但如果 Agent 能在交互中进化呢？

Multi-Agent Evolve (MAE): LLM Self-Improve through Multi-Agent Co-evolution
2025.10 · arXiv
Self-Play Co-evolution Judge-based Evaluation General Domain Applicable

将Self-Play 范式扩展到通用领域：多个 Agent 互相对抗/协作，引入 Judge 评估（不再要求零和博弈），Agent 在交互中共同进化，能力持续提升。

Smallville 的 Agent 是静态的认知体——它们积累记忆但不提升能力。MAE 提出的共同进化机制如果嵌入 Smallville，Agent 可以在社交互动中变得越来越善于社交——这才是真正的"模拟人类成长"。
A Survey of Self-Evolving Agents: What, When, How, and Where to Evolve
2025.07 · arXiv (updated 2026.01)
Self-Evolving Agent Taxonomy Lifelong Agentic Systems Path to ASI

LLM 本质上是静态的——无法适应新任务、演化知识或动态交互。这篇综述系统梳理了让 Agent 自我进化的路径：什么时候进化、怎么进化、在哪里进化。

这篇综述把 Smallville 定位为"静态 Agent 在动态环境中运行"的经典案例，并指出了下一步：Agent 本身也必须进化。Voyager（技能库增长）是一个方向，MAE（参数进化）是另一个。
Self-Evolving Multi-Agent Framework for Efficient Decision Making in Real-Time Strategy Scenarios
2026.03 · arXiv
RTS Self-Evolution Strategy Adaptation

在即时战略（RTS）场景中，多 Agent 自我进化决策框架：Agent 通过对局经验自动调整策略，适应对手变化。

如果 Smallville 加入竞争要素（资源争夺、社会地位），Agent 是否也能自我进化出更复杂的社会策略？这篇论文在游戏领域验证了可行性。

从 Smallville 到多 Agent 前沿：演进脉络

Smallville 的五个"未回答的问题"，以及这些论文如何回答它们：

Smallville 的局限 2025-2026 的回答 代表论文
为什么合作？
只观察到涌现，没解释机制		 LLM 内置的公平偏好驱动合作；压力水平决定合作程度；不同模型/语言有不同策略倾向 Yerkes-Dodson Curve, Game Theory Analysis, Competition & Cooperation

Agent 的"礼貌/友善"来自 Prompt		 规范可以从底层交互中自发涌现；价值观多样性的群体涌现更丰富的规范 Social Learning & Norm Formation, Value Diversity

记忆增长但能力不变		 多 Agent 共同进化可以持续提升能力；Self-Play + Judge 评估使进化不限于零和场景 Multi-Agent Evolve, Self-Evolving Agents Survey
一个更深层的洞察：Smallville 的"涌现"可能有很大一部分不是真正的涌现，而是 LLM 训练数据中人类社会行为模式的重放。Emergent Coordination 论文提供了区分"真涌现"和"伪涌现"的方法；Game Theory 系列论文则证明 LLM 内置了特定的策略偏好（如公平偏好、终局背叛）。这意味着 Smallville 观察到的社会行为，部分是设计的产物（记忆+反思+规划），部分是训练数据的泄漏（LLM 的内置偏好）。未来的多 Agent 研究需要严格区分这两者。
