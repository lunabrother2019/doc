代码复现计划（按难度递进）

P1 跑通 Agent4Rec + 记录 baseline 3-5 天 · ~$16
git clone Agent4Rec → 配 OpenAI API → 1000 Agent 全量跑
记录：评分分布 KS 距离 / 1:1 matching accuracy / filter bubble 涌现
分析低评分偏差（1-2 星缺失程度）
P1 产出
baseline 数据 + 对 L1 偏差的直观理解。后续所有实验以此为对照。
P2 集成 UserMirrorer 替代 frozen-LLM 1-2 周 · 需 GPU
git clone UserMirrorer → 跑通 SFT/DPO 训练
用 MovieLens 数据训练 user simulator 小模型
替换 Agent4Rec 中的 LLM 调用为 UserMirrorer 模型
对比：UserMirrorer vs frozen-GPT-3.5 的 KS 距离 / matching accuracy
P2 产出
L1 偏差是否显著改善？如果是 → "微调 > prompting" 的实证。可写 short paper。
P3 闭环稳定性实验（L2 核心） 2-3 周 · ~$60-120
基于 AFL 或 Agent4Rec 搭建 Agent↔RecSys 闭环
跑 N=100 轮，逐轮记录 Δ(n) = KL(D_sim(n) || D_real)
消融：有记忆 vs 无记忆 vs 有记忆无反思 vs UserMirrorer
消融：MF vs LightGCN vs DNN vs Random 推荐算法
画 Δ(n) 曲线 → 收敛/发散/振荡？
度量 OmniBehavior 定义的 homogenization 指标
P3 产出
全新研究空白。三种可能结果都可发论文：
  • 发散 → "Warning: Feedback Loop Instability in LLM Agent Simulation"
  • 收敛 → "Memory as Stability Anchor for Agent-RecSys Feedback Loops"
  • 有条件收敛 → "Conditions for Stable Agent-based Recommendation Simulation"
P4 A/B 方向预测（L3） 3-4 周 · ~$80-160
用 KuaiRand 15 种策略 log 计算真实效果排序
用 UserMirrorer simulator + RecSim NG 环境模拟每种策略
收集仿真结果 → 计算策略排序
Spearman rank correlation ρ（仿真排序 vs 真实排序）
降级方案：pairwise accuracy（每对策略的方向预测正确率）
参考 SimUSER 的 A/B 验证方法论 + Open Bandit Pipeline 的 OPE 评估
P4 产出
如果 ρ > 0.7 → Agent 仿真有方向预测能力 → 可替代 A/B 粗筛 → 重磅论文。 如果 ρ < 0.5 → 需要回到 L1/L2 继续改进 simulator 质量。
P5 扩展方向（可选） 持续
TriRec 三方 Agent 博弈 → 公平性研究
PUB Big Five 人格 → 更丰富的 persona 初始化
ALCS 记忆压缩 → 给 reflection 加置信度（理论贡献）
OASIS 百万级规模 → 社交传播现象仿真
Mem0 SDK 集成 → 替换 Agent4Rec 记忆后端
