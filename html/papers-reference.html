必读

Large Language Models Cannot Self-Correct Reasoning Yet ↗ · 深度解读 →
2024 · ICLR · Huang, Chen, Tao, Feng, Yu, He
Self-Reflection Limitations Confirmation Bias External Feedback Necessity ~2% True Correction Rate
必读

分水岭论文。发现：90%+ 的 LLM 自我反思是确认性的（反思完还是维持原答案），真正纠错只占 ~2%。结论：没有外部反馈时，LLM 自我反思几乎无效。

这篇论文迫使整个领域转向：从"让 Agent 自己反思"转向"引入外部批评者"或"用 RLHF 等训练信号替代显式反思"。后续的多 Agent 辩论、跨轨迹经验反思都是对这篇论文的回应。
