推理链 — 从单链到集体搜索

Reasoning Evolution · 4 篇
CoT2022 → ToT2023.05 → LATS2023.10 → Multi-Agent ToT2024.09
1 / 4 Chain-of-Thought (CoT) NeurIPS 2022 · Wei et al. (Google)
arXiv 2201.11903 深度解读 →
一句话核心让 LLM 输出答案前先写"中间推理步骤",GSM8K 从 18% → 74%,无需任何微调。
地位整条链的起点。没有这篇,下面三个工作都无从谈起。是 LLM "涌现推理能力"的决定性证据。
2 / 4 Tree of Thoughts (ToT) NeurIPS 2023 · Yao et al. (Princeton/Google)
arXiv 2305.10601 深度解读 → Code
一句话核心把 CoT 的"思维链"扩展成"思维树",每步生成多个候选,允许 回溯和并行探索。
相对 CoT从单路径贪心升级到多路径搜索。遇到 24 点数学题、创意写作这类需要尝试的任务,准确率大幅提升。
3 / 4 LATS — Language Agent Tree Search ICML 2024 · Zhou et al.
arXiv 2310.04406 深度解读 → Code ⚡ 同时属于反思链
一句话核心用 MCTS 统一 ReAct + ToT + Reflexion,一个 LLM 同时扮演行动生成器 / 价值函数 / 反思器三重角色。
相对 ToTToT 只在推理空间搜索,LATS 把搜索扩到行动空间(能与环境交互),并在搜索过程中实时反思 —— 这是三篇前置工作的集大成者。
4 / 4 Multi-Agent ToT Validator arXiv 2024.09
arXiv 2409.11527 深度解读 → Code
一句话核心多个 Reasoner Agent 并行跑 ToT,再由专门的 Validator Agent 做外部逻辑批评,两者博弈产出最终答案。
相对 LATSLATS 让同一个 LLM 自己评价自己,难免"自证偏见"。本工作引入独立批评者,把"集体推理"形式化,是从"搜索"走向"辩论"的关键一步。

行动链 — 从闭环反馈到终身学习

Action Evolution · 4 篇
Inner Monologue2022.07 → ReAct2022.10 → Plan-and-Solve2023.05 → Voyager2023.05
1 / 4 Inner Monologue CoRL 2022 · Huang et al. (Google / Everyday Robots)
arXiv 2207.05608 深度解读 →
一句话核心把 LLM 的自我对话嵌入机器人闭环控制,通过感知/成功检测/人类反馈重新规划 —— 最早的具身 LLM Agent。
地位早于 ReAct 3 个月,是"LLM + 环境交互"的史前形态,核心主张:LLM 需要持续的语言反馈才能纠偏。
2 / 4 ReAct ICLR 2023 · Yao et al. (Princeton/Google)
arXiv 2210.03629 深度解读 → Code
一句话核心Thought → Action → Observation 交替的 loop 范式。所有后续 Agent 框架都是它的变体。
相对前者Inner Monologue 只在具身场景,ReAct 把"推理-行动交错"通用化到任意工具调用 / 问答 / 搜索任务,成为 LangChain / AutoGPT 等工程化框架的蓝本。
3 / 4 Plan-and-Solve ACL 2023 · Wang et al.
arXiv 2305.04091 深度解读 → Code
一句话核心在 CoT 基础上显式拆成两阶段:先让 LLM 输出完整计划,再按计划逐步求解。
相对 ReActReAct 是"边想边做",容易被局部错误带偏。Plan-and-Solve 强制"先想完再做",在数学/推理类任务上更稳定,是"规划优先"思想的代表。
4 / 4 Voyager arXiv 2023.05 · Wang et al. (NVIDIA/Caltech)
arXiv 2305.16291 深度解读 → Code
一句话核心Minecraft 里的 GPT-4 Agent:自动课程(自己给自己出任务) + 技能库(把学会的代码存起来) + 迭代 prompt。
相对前者ReAct / Plan-and-Solve 做单次任务,Voyager 第一次证明 LLM Agent 能自主成长 —— 今天的技能成为明天的工具。行动链在此从"一次性决策"走向"终身学习"。

1 / 5 Generative Agents (Smallville) UIST 2023 Best Paper · Park et al. (Stanford/Google)
arXiv 2304.03442 深度解读 → Code ⭐18k ⚡ 同时属于反思链
一句话核心扁平时间序列 Memory Stream,每条记忆独立存在,按 recency × importance × relevance 三分打分取 top-k 检索。
地位所有现代 Agent 记忆系统的起点。朴素但完整 —— 25 个 Agent / 2 天仿真下运行良好,但在长时尺度下必然崩溃,后续 4 篇都是对它的攻击。
2 / 5 HiAgent arXiv 2024.08 · Hu et al. (HKU/Shanghai AI Lab)
arXiv 2408.09559 深度解读 → GitHub
一句话核心双层工作记忆:子目标栈(高层只存阶段摘要) + 行动-观察窗口(底层只存当前子目标相关),LLM 主动决定何时"结案"。
相对 Smallville从扁平到分层。长程任务上下文从 O(N) 压到近似 O(1),5 个基准上成功率 ~2x,步数 -3.8。任务驱动的结构化压缩。
3 / 5 A-MEM NeurIPS 2025 · Xu et al.
arXiv 2502.12110 深度解读 → GitHub
一句话核心Zettelkasten(卡片笔记法)式关联网络:每条新记忆写入时,LLM 自动判断与哪些已有记忆建边,形成知识图谱。
相对 HiAgent从层级到图网络。HiAgent 的分层是任务驱动的,A-MEM 的图是语义驱动的 —— 检索从"打分排序"变成"节点定位 + 沿边扩展"。
4 / 5 Memori arXiv 2026
arXiv 2603.19935 深度解读 →
一句话核心把对话并行拆成语义三元组(主-谓-宾) + 会话摘要,用 FAISS + BM25 混合检索。
相对 A-MEMA-MEM 的边由 LLM 临机判断(语义模糊),Memori 用显式的 (s, p, o) 结构约束记忆表示。仅用 5% token 达到 81.95% 准确率,成本降 20x。数据驱动的记忆压缩。
5 / 5 MemoryOS EMNLP 2025 Oral · Kang et al. (BAI-LAB)
arXiv 2506.06326 深度解读 → GitHub
一句话核心三级存储(短 / 中 / 长)+ FIFO 对话链 + 分段分页 —— 把计算机 OS 内存管理思想搬到 LLM 记忆。
相对前四者前四者都是结构层面的创新(扁平 → 层级 → 图 → 三元组),MemoryOS 回到系统层面 —— 引入调度与淘汰策略。LoCoMo 上 F1 +49.11%、BLEU-1 +46.18%。它不替代前者,而是提供了一个正交的视角。

反思链 — 从周期抽象到搜索内反思

Reflection Evolution · 3 篇
Smallville
阈值触发2023.04 → Reflexion
失败即学习2023.03 → LATS
搜索内反思2023.10
1 / 3 Generative Agents (Smallville) UIST 2023 · Park et al.
arXiv 2304.03442 深度解读 → Code ⭐18k ⚡ 同时属于记忆链
反思机制当最近记忆的 importance 累积值超过阈值(原文 150)时触发。LLM 从 100 条最近记忆里先生成 3 个问题,再分别检索回答,生成高阶洞察作为新记忆写回。
特点周期性的离线批处理,像"季度总结"。递归结构:洞察本身也能被下一次反思进一步抽象,形成反思树。
2 / 3 Reflexion NeurIPS 2023 · Shinn et al.
arXiv 2303.11366 深度解读 → Code
反思机制任务失败后,LLM 对失败轨迹生成语言形式的"教训"(Verbal Reinforcement Learning),附加到下次试验的 prompt,实现无梯度的自我改进。
相对 SmallvilleSmallville 的反思是无监督的(没有对错信号),Reflexion 由失败信号驱动。这是从"周期性抽象"到"失败即学习"的关键转变 —— 反思不再是装饰,而是学习的载体。
3 / 3 LATS — Language Agent Tree Search ICML 2024 · Zhou et al.
arXiv 2310.04406 深度解读 → Code ⚡ 同时属于推理链
反思机制MCTS 搜索过程中,每遇到失败叶子节点就 实时调用 LLM 生成经验总结,注入后续搜索迭代的 prompt。
相对 ReflexionReflexion 是episode 结束后反思,LATS 把反思嵌入搜索过程本身。这是从"回合级反思"到"节点级反思"的进一步细化 —— 反思的粒度与搜索的粒度对齐。

1 / 2 CAMEL NeurIPS 2023 · Li et al.
arXiv 2303.17760 深度解读 → Code ⭐ 框架
一句话核心双角色扮演框架:AI User(出题)+ AI Assistant(解题),通过对话协作完成复杂任务。Role-playing 作为一级抽象。
地位第一个结构化的多 Agent 协作框架,是 MetaGPT / ChatDev / AutoGen 等后续"角色分工"系统的直接祖先。
2 / 2 AgentSociety arXiv 2025.02 · Chen et al. (Tsinghua)
arXiv 2502.08691 深度解读 → GitHub
一句话核心把 Smallville 从 25 Agent 扩展到 10,000+,产生 500 万次交互。用分层记忆 + 异步调度 + 分级推理解决规模化挑战。
相对 CAMELCAMEL 关心两个 Agent 如何协作,AgentSociety 关心10,000 个 Agent 能否产生社会动态。从"协作微观"跃迁到"社会宏观" —— 回答了"小镇架构能否规模化"这个根本问题。

跨链观察 — 同一篇论文为何出现在多条链上

两篇"双料"论文

  • Smallville (Generative Agents) 同时是记忆链的起点和反思链的起点。这不是巧合 —— Memory Stream 和 Reflection 是同一架构的两面:Reflection 读 Memory Stream 作为输入,生成的洞察又写回 Memory Stream。 后续的分离研究(A-MEM 专攻结构、Reflexion 专攻学习)都是对这个统一体的拆解。
  • LATS 同时是推理链的终点之一和反思链的终点。这揭示了一个深层事实: 推理和反思在数学上是对偶的 —— 推理是前向搜索(生成候选),反思是后向评估(从失败中提取信号)。 LATS 的贡献是把这两个方向合并到同一个 MCTS 循环里,这也是它被视为"集大成之作"的原因。

五条链之间的隐含耦合

  • 推理链 ↔ 行动链:ReAct 的名字就是 Reasoning + Acting,LATS 把两者合并到同一搜索空间。推理不可能脱离行动,行动也需要推理指导。
  • 记忆链 ↔ 反思链:记忆是反思的原料,反思的产物又是记忆。它们共享同一个存储底层 —— A-MEM 的 Memory Evolution 实际上就是"在线反思"。
  • 多 Agent 链是其他四条链的放大器:AgentSociety 里每个 Agent 都要跑记忆 + 反思 + 规划 + 行动,10,000 个 Agent 把每条链的成本瓶颈都放大 400 倍,这是后续研究的压力测试。

如果只读 5 篇 —— "黄金五篇"

按学习顺序而非时间顺序:

  1. CoT(2022)—— 理解 LLM 推理能力
  2. ReAct(2022)—— 理解 Agent loop 范式
  3. Smallville(2023)—— 理解完整 Agent 架构 核心
  4. Reflexion(2023)—— 理解自我改进机制
  5. LATS(2023)—— 理解 Agent 决策的统一框架
