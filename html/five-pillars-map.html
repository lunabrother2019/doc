外围启发 ALCS — 自动折叠采样 (Cambridge 2026)
Laplace近似潜变量边缘化自动微分嵌套采样贝叶斯推断
用 MAP + Laplace 近似将高维潜变量"折叠"成标量贡献，有效维度从 d_θ+d_z 降至 d_θ。与 Agent 记忆的概念桥接：记忆压缩 ≈ 潜变量折叠；未来可为记忆加不确定性量化（置信度建模）。目前无直接引用关系，属于跨领域方法论启发。
外围启发 TimesFM — 时间序列基础模型 (Google, ICML 2024)
Decoder-only1000亿数据点zero-shot预测Patch机制BigQuery集成
将 LLM 的 decoder-only 范式迁移到时间序列预测，200M 参数 + 1000 亿真实数据点预训练实现 zero-shot 泛化。与 Agent 的概念桥接：可作为 Agent 的环境预测模块（World Model），在规划阶段 zero-shot 预测不同行动的后果。
