15 个核心概念详解

1Memory Stream
记忆流
按时间顺序存储 Agent 所有经历的基础数据结构。几乎每一篇 Generative Agents 相关论文都以此为起点，是整个架构的根基。后续所有记忆系统的创新（层级记忆、关联网络、共享记忆）都是对它的扩展。
Generative Agents (2023) A-MEM (2025) HiAgent (2024)
2Reflection
反思机制
Agent 定期对记忆进行高层归纳的能力。从最初的"重要性阈值触发"到被发现 90% 是确认性反思，再到多智能体辩论、双环元认知等修复方案，是整个领域认知翻转最剧烈的概念。
原版 Reflection (2023) Reflexion (NeurIPS 2023) Self-Correct 局限 (ICLR 2024) Dual-Loop (2025) ERL (2025)
3Recency × Importance × Relevance
三维检索评分
原始论文定义的记忆检索公式，用时间衰减、LLM 打分的重要性和语义相关度三个维度加权排序记忆。看似简单，但"重要性由谁定义"这个问题至今没有完美解，后续被 Cross-Attention 网络和关联图谱等方案挑战。
Generative Agents (2023) Cross-Attention 替代 (2025)
4Emergent Behavior
涌现行为
个体 Agent 遵循简单规则却在群体层面产生无指令的复杂社会协作（如自发组织派对）。所有大规模仿真论文的核心观测目标，但最难被预测和复现——没有一篇论文能从第一性原理推导出涌现现象。
Generative Agents (2023) AgentSociety (2025) OpenCity (2025)
5Hierarchical Planning
层级规划
将长程目标递归分解为日→时→分钟级行动的规划机制。原始论文中 Agent 先生成日计划再逐步细化。HiAgent 以子目标切分记忆，ChatDev/MetaGPT 用角色流程编排实现任务分解。长程规划的一致性问题仍是难点。
Generative Agents (2023) HiAgent (2024) ChatDev (ACL 2024)
6ReAct
推理+行动交替
提出将 Reasoning 与 Acting 交替执行的范式：Agent 在每步行动前先生成思维链推理，支持工具调用。是现代 Agentic AI（搜索、代码执行、API 调用）的基础范式，几乎所有可落地的 Agent 系统都采用此模式。
ReAct (ICLR 2023)
7RLHF / Alignment
人类反馈对齐
通过人类反馈强化学习使 LLM 行为符合人类期望。是 Character.AI Personality Embeddings 和所有商业 Agent 角色一致性训练的方法论基础。没有 RLHF，Agent 无法稳定扮演特定角色。
InstructGPT (NeurIPS 2022)
8Multi-Agent Debate
多智能体辩论
让多个 Agent 互相批评对方答案并通过辩论达成共识。直接回应"自我反思 90% 无效"的发现——引入外部批评者打破确认偏差，GSM-8K 从 82% 提升至 91%。是反思失效后整个领域的主要转向方向。
MAD (2023) MAR (2024)
9Role-Playing / Persona
角色扮演
为 Agent 赋予特定角色身份和行为模式。学术端用于 ChatDev（程序员/测试员分工）和 MAR（异质角色批判）；商业端被 Inworld AI（游戏 NPC）和 Character.AI（角色对话）大规模落地。角色一致性维持是核心挑战。
ChatDev / MetaGPT (ACL 2024) MAR Persona Diversity (2024)
10Episodic Memory
情节记忆
存储 Agent 完整任务经历（成功/失败轨迹）的记忆类型。Reflexion 将语言反思写入 episodic memory 供下次重试调用；ERL 比较历史轨迹提取可复用 heuristics；Dual-Loop 用反思银行实现持续自我改进。是跨任务经验积累的核心容器。
Reflexion (NeurIPS 2023) ERL (2025) Dual-Loop (2025)
11LLM + ABM Fusion
LLM + Agent-Based Modeling 融合
将 LLM 的行为生成能力与传统 Agent-Based Modeling 的涌现规律可控性结合。Nature 和 Physica A 两篇综述系统分析了该融合在经济学、社会学、政治学中的应用潜力，代表社会科学接入 AI 的方法论前沿。
Nature 综述 (2024) Physica A 综述 (2024)
12Validation Gap
仿真验证问题
所有 Agent 仿真论文都在回避的根本问题：仿真结果怎么证明它对应真实人类行为？Springer AI Review 的批判性评述指出验证（Validation）是最关键的未解决问题——仿真数据缺乏 Ground Truth 对照，科学可靠性存疑。
Critical Perspectives (Springer 2025)
13Chain-of-Thought
思维链
让 LLM 在回答前显式生成中间推理步骤。是 ReAct 推理-行动交替和 Reflection 反思归纳的底层机制。没有 CoT，Agent 就无法进行多步推理，也无法产生有意义的反思内容。
Chain-of-Thought Prompting (NeurIPS 2022) ReAct (ICLR 2023)
14World Model
世界模型
为 Agent 提供物理世界约束仿真的模块。CVPR 2025 提出 MLLM 负责高层语义规划、World Model 提供物理约束的双驱动架构。是 Agent 从纯语言空间落地到物理世界的关键缺口。
Generalist Embodied Agents (CVPR 2025)
15Associative Memory Network
关联记忆网络
受 Zettelkasten 卡片笔记启发，将线性记忆流升级为知识图谱式关联网络。每条记忆带关键词与标签，与相关记忆动态建立语义链接，提升跨事件推理能力。代表记忆系统的下一代演进形态。
A-MEM (2025)
